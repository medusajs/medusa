Shared constants, types, and utilities for Medusa's admin packages, such as the list of widget injection zones (`INJECTION_ZONES`, `InjectionZone`) and custom field, route, and layout extension types. It's internal plumbing used by `@medusajs/admin-sdk`, `@medusajs/admin-vite-plugin`, `@medusajs/admin-bundler`, and `@medusajs/dashboard`; you don't need to install or import it directly to build admin extensions.
