The runtime that executes Medusa workflows. It runs each workflow as a compiled graph of steps and keeps all run state in PostgreSQL, so the same engine serves development and production, and a single instance as well as many server and worker instances. Retries, timeouts, async steps, scheduled workflows, crash recovery and grouped event delivery are built on the saved state. An in-memory store runs it without a database for development and tests.

It is used through the [Workflow Engine Module](../../modules/workflows), which Medusa registers by default; define workflows with `@medusajs/framework/workflows-sdk`. See [ARCHITECTURE.md](./ARCHITECTURE.md) for how it works.

## Installation

No installation needed. The engine ships with `@medusajs/medusa`.
