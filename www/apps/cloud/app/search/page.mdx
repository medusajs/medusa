# {metadata.title}

In this guide, you'll learn how to enable external search access for your environment and use the search endpoint for local development.

## What is the Search Endpoint?

The search endpoint gives external clients access to your environment's search functionality. You can use the search endpoint URL during local development to connect your local Medusa application to the Cloud environment's search service.

---

## Enable External Search Access

<Note>

This feature is only available when enabled for your organization. If you don't see the **Search** section under your environment's storage settings, contact support.

</Note>

To enable or disable external search access for an environment:

1. From the [organization's dashboard](../organizations/page.mdx), click on the environment's project.
2. In the project's dashboard, click on the name of the environment. For example, "Production".
3. Click **Database & Storage** > **Storage** in the sidebar.
4. In the **Search** section, toggle the switch to enable or disable external search access.

<Note type="warning">

On production environments, only organization owners can enable external search access. You will be prompted to confirm before the change takes effect.

</Note>

When external search access is enabled, a read-only code block appears showing the search endpoint URL. You can use this URL in your local development setup to connect to the environment's search service.

---

## Use the Search Endpoint Locally

After enabling external search access, copy the search endpoint URL shown in the **Search** section and configure it in your local Medusa application to connect to the Cloud environment's search service.
