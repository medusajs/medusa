# {metadata.title}

In this guide, you'll learn how to create your first project in Cloud after you sign up, either from a starter or from your own GitHub repository.

## Create a Project After Sign Up

After you [sign up](../sign-up/page.mdx) and finish setting up your account, Medusa redirects you to your organization's projects list.

When your organization has no projects yet, the projects list shows two options to create your first project:

1. [Browse starters](#option-1-choose-a-starter): Start from a starter that Medusa has built, with use cases related to DTC, B2B, and more.
2. [Import repository](#option-2-import-a-repository): Import a Medusa project hosted on your GitHub account or organization.

After following either flow, you'll have an ecommerce project deployed to Cloud. Choose the option that best fits your use case.

---

## Option 1: Choose a Starter

Choose from a variety of pre-built templates that fit your use case to get started quickly. By choosing a template, you'll have an ecommerce store with the necessary foundation, with the flexibility to customize it for your unique store.

To create a project from a starter:

1. In the projects list, click on the **Browse starters** card.
2. Browse the list of starters to find the store that fits your use case.
  - To show only starters of a specific category, click the **DTC** or **B2B** filter button. Click **All** to show all starters again.
  - To view more details about a starter, such as its features and the storefront framework used, click its **Preview** button.
3. To create a project from a starter, click its **Deploy** button.
4. Follow the project creation steps. Refer to the [Projects guide](../projects/page.mdx#1-create-project-from-a-starter) for more information on creating projects from starters.

Once your project is deployed, you're ready to use your ecommerce store and start selling.

Cloud clones the starter into a GitHub repository in your account or organization. To customize the store, refer to the [Clone a Cloud Project Locally](../projects/clone-locally/page.mdx) guide.

---

## Option 2: Import a Repository

If you have a Medusa application hosted on GitHub, you can import it to create a project.

To create a project from your GitHub repository:

1. In the projects list, click on the **Import repository** card.
2. Follow the project creation steps, including choosing your repository to import it. Refer to the [Projects guide](../projects/page.mdx#2-create-project-from-an-existing-application) for more information on creating projects.

Once your project is deployed, you're ready to use your ecommerce store and start selling.
