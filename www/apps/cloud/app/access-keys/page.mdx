In this guide, you'll learn how to create and manage access keys to authenticate with Cloud APIs.

## What are Access Keys?

Access keys are API credentials that allow you to authenticate with Cloud services programmatically. They provide secure access to your Cloud resources without requiring interactive login.

Cloud supports two types of access keys:

- **Organization Access Keys**: Provide access to organization-level resources and settings
- **Personal Access Keys**: Provide access to your personal account resources

---

## Manage Organization Access Keys

Organization access keys allow API access to organization-level resources such as projects, environments, and billing information. These keys are managed by organization owners and administrators.

To manage organization access keys:

1. [Open your organization's settings](../organizations/page.mdx#view-organization-settings).
2. Click on the **Access Keys** tab in the sidebar (marked with a <InlineIcon Icon={ShieldCheck} alt="shield" /> icon).

From this page, you can view all organization access keys, including their titles, redacted key previews, and creation dates.

### Create Organization Access Key

To create a new organization access key:

1. In the Organization Access Keys page, click **Create Access Key**.
2. In the modal that appears, enter a **Title** for your access key. Choose a descriptive name that helps you identify the key's purpose.
3. Click **Create**.

After creation, the full access key token will be displayed with a copy button. Make sure to copy and store this token securely, as it won't be shown again.

<Note type="warning">

Store your access key securely. Once you close the creation dialog, you won't be able to view the full key again. If you lose it, you'll need to create a new one.

</Note>

### Rename Organization Access Key

To rename an existing organization access key:

1. In the Organization Access Keys table, find the key you want to rename.
2. Click the <InlineIcon Icon={EllipsisHorizontal} alt="three dots" /> button in the key's row.
3. Select **Rename** from the dropdown menu.
4. Enter the new title and click **Save**.

### Delete Organization Access Key

<Note type="warning">

Deleting an access key will immediately revoke API access for any applications or scripts using that key. This action cannot be undone.

</Note>

To delete an organization access key:

1. In the Organization Access Keys table, find the key you want to delete.
2. Click the <InlineIcon Icon={EllipsisHorizontal} alt="three dots" /> button in the key's row.
3. Select **Delete** from the dropdown menu.
4. Confirm the deletion in the confirmation dialog.

## Manage Personal Access Keys

Personal access keys provide API access to your individual account resources. These keys are private to your account and can only be managed by you.

To access your personal access keys:

1. Click on your name and avatar at the top right of the Cloud dashboard.
2. Choose **Account settings** from the dropdown.
3. Click on the **Personal Access Keys** tab in the sidebar (marked with a <InlineIcon Icon={CommandLine} alt="command line" /> icon).

From this page, you can view all your personal access keys, including their titles, redacted key previews, and creation dates.

## Best Practices

When working with access keys, follow these security best practices:

- **Use descriptive titles**: Name your keys based on their intended use (for example, "CI/CD Pipeline" or "Monitoring Scripts")
- **Rotate keys regularly**: Create new keys periodically and delete old ones to maintain security
- **Limit scope**: Use personal access keys for individual projects and organization keys only when broader access is needed
- **Store securely**: Keep your access keys in a secure location such as environment variables or a password manager
- **Monitor usage**: Review your access keys regularly and delete any that are no longer needed
