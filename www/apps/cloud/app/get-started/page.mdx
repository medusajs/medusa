# {metadata.title}

When you first create an organization on Medusa Cloud, you'll be guided through a streamlined onboarding experience to help you create your first project quickly and efficiently.

The get started flow is designed for new organizations with no existing projects, providing three clear paths to get your Medusa application up and running on Cloud.

---

## Onboarding Options

The get started experience offers three distinct paths to create your first project:

### AI-Assisted Project Creation

Create a new Medusa project with the help of artificial intelligence:

1. **Describe Your Project**: Use the AI prompt interface to describe your project requirements, business needs, and desired features.
2. **Generate Project Structure**: The AI assistant will help generate a project structure and codebase based on your requirements.
3. **GitHub Integration**: After your project is created locally, you can import it from your GitHub repository to deploy on Cloud.

This option is ideal if you want to create a custom project tailored to your specific business requirements with AI guidance.

### Starter Template Selection

Choose from a variety of pre-built templates to quickly start your project:

- Browse available starter templates including DTC, B2B, and specialized commerce applications
- Each template includes a complete storefront, backend, and admin dashboard
- Templates cover various use cases from standard ecommerce to specialized industries
- Direct navigation to the new project creation form when you select a template

This option is perfect if you want to start with a proven template and customize it for your needs.

### GitHub Repository Import

Import an existing Medusa application from your GitHub repository:

- Import projects you've already developed locally
- Migrate existing Medusa applications to Cloud
- Maintain your current codebase and development workflow

This option is best if you already have a Medusa application and want to deploy it to Cloud.

---

## Navigation and Flow

### Path Selection

The get started flow begins with a path selection screen showing three clickable cards, each representing one of the onboarding options. Each card displays:

- A descriptive icon (sparkle for AI, swatch for templates, GitHub logo for import)
- Clear title and description
- Arrow indicator to proceed

### Step-by-Step Process

For AI-assisted project creation, you'll progress through numbered steps:

1. **Step 1**: AI prompt interface for describing your project
2. **Step 2**: GitHub repository import with import button
3. Progress indicators show your current position in the flow
4. Back button available to return to previous steps

### Smart Navigation

- Back buttons appear contextually when needed
- If you already have existing projects, you'll be automatically redirected to the projects page
- Special routing ensures smooth navigation between get started flow and regular project creation

---

## Getting Started

To access the get started flow:

1. Sign up for a new Medusa Cloud account or create a new organization
2. When you first access your organization dashboard with no existing projects, you'll automatically see the get started options
3. Choose the path that best fits your needs and follow the guided steps

If you need to access the get started flow again later, you can do so from your organization dashboard when you have no active projects.
