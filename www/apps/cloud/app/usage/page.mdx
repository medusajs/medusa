# {metadata.title}

In this guide, you'll learn how to monitor your Cloud organization's standard and Flex Usage.

## View Usage on Cloud

In your organization's settings, you can view your current plan and usage limits. These usage limits depend on the plan your organization is on, and are applied across all projects within the organization.

<Note>

Organizations on the Enterprise plan don't have usage limits, and therefore don't have a **Usage** item in the sidebar.

</Note>

To view your organization's usage:

<Note title="Tip">

You can also navigate to an organization's usage from the [command palette](../command-palette/page.mdx). Press <Kbd>{getOsShortcut()}</Kbd> + <Kbd>K</Kbd> and select **Usage**.

</Note>

1. Make sure you're viewing the [correct organization's dashboard in Cloud](../organizations/page.mdx#switch-organization).
2. Click **Usage** in the sidebar to open the organization's usage settings.

In the Usage settings, you'll find a table with the list of resources your organization is using, along with their current usage levels and limits based on your plan.

### Usage Metrics Definitions

The following metrics are tracked and billed as part of your Cloud usage:

- **Data Transfer**: The data that flows in and out of your Medusa server each month, including API responses to your storefront, Admin Dashboard traffic, webhook calls, and external service communications.
- **Server Transfer**: The data transferred between internal services within your Cloud environment each month, such as between data between the Medusa application and your database.
- **Compute**: The CPU and memory resources used to run your Medusa applications and background processes, measured in compute units per hour.
- **Object Storage**: The amount of file storage space used for assets like product images, documents, and other media files, measured in gigabytes (GB).
- **Database Storage**: The disk space used by your database to store your commerce data, including products, orders, customers, and other business data, measured in gigabytes (GB).
- **Redis Storage**: The disk space used by Redis to store your application's cache and session data, measured in gigabytes (GB).
- **Build Minutes**: The time taken to build your Medusa applications during deployments, measured in minutes.
- **Emails**: The number of emails sent from your Medusa applications, including order confirmations, password resets, and marketing emails.
- **Freetext search requests**: Keyword search requests your Medusa applications make with [Medusa Search](../search/page.mdx).
- **Vector search requests**: [semantic search](../search/semantic-search/page.mdx) requests your Medusa applications make with [Medusa Search](../search/page.mdx).
- **Storefront Requests**: The number of requests made to your storefront. Every page load or API call to your storefront counts as a request.
- **Webhooks**: The number of webhook event deliveries sent from your organization to your configured endpoint.

### Usage Table Allowance Breakdown

When you view a single billing cycle and your organization has [credits](#view-organization-credits) for a metric, the quantity column of the usage table shows a second line that breaks down the metric's allowance into the portion from your plan and the portion from your credits. For example, `500 from plan + 100 from credits`.

## View Organization Credits

Credits add to your plan's allowance for a specific feature, reducing the usage that counts as [Flex Usage](#what-is-flex-usage).

If your organization has credits, the Usage settings show a **Credits** section above the usage charts. The section isn't shown if your organization has no credits.

### Credits Table Columns

The **Credits** section has a table listing each credit with the following columns:

- **Feature**: The name of the feature that the credit applies to, along with the date the credit became active.
- **Type**: The credit's type, such as subscription or one-time.
- **Status**: The credit's status:
  - Green: The credit is active.
  - Orange: The credit expires within 14 days.
  - Grey: The credit is used up or expired.
- **Balance**:
  - For subscription credits, the allowance the credit provides in each billing cycle. Cloud doesn't track the consumption of subscription credits individually.
  - For other credits, a chart showing the used quantity against the total quantity, along with the remaining balance. If you consumed part of the credit in the current billing cycle, the column also shows that consumption.
- **Expires**:
  - For subscription credits, **Renews each cycle**.
  - For credits without an expiration date, **Never expires**.
  - For other credits, the expiration date and the relative time until it, such as "in 3 days".

The table shows credits that expire soon first, followed by active, used-up, and expired credits. Within each status, the table sorts credits by their expiration date.

### Show Expired Credits

If at least one of your organization's credits has expired, the **Credits** section shows a **Show expired** toggle. Enable the toggle to include expired credits in the table, or disable it to hide them.

## What is Flex Usage?

Your organization has a set of usage limits based on its current [plan](../pricing/page.mdx). These usage limits are applied across all projects within the organization.

Usage that exceeds the limits of your plan is considered Flex Usage. For example, if your plan allows for 100GB data transfer, any usage beyond that limit would be classified as Flex Usage.

To learn how your Flex Usage is billed, refer to the [Billing](../billing/page.mdx) guide.

### Monitor Flex Usage

You can view additional Flex Usage for each resource and its charge in the [usage table](#view-usage-on-cloud). For each resource, the table has the following columns useful for monitoring Flex Usage:

- **Flex**: The amount of usage beyond your plan limits. For example, the additional data transfer amount.
- **Charge**: The cost associated with the Flex Usage.

If you have Flex Usage, you can also see the flex charges visualized in the chart above the table.

If your organization has [credits](#view-organization-credits), the flex charges chart also shows the usage that your credits covered as a yellow segment stacked on top of each day's charges. Hover over a day to see its **Credited** amount in the tooltip.

### Usage Chart Per Resource

In the "Billable metrics" section of the Usage settings, you can view a chart for each resource showing your usage over time with forecasted usage. For example, you can view the usage chart for data transfer, Compute, object storage, etc...

#### Usage Chart Types

At the top of the "Billable metrics" section, you can find a "Cumulative" toggle. When enabled, the charts will display cumulative usage over time. When disabled, the charts will show daily usage.

Cumulative usage helps you understand the total usage up to a specific date, while daily usage provides insights into your usage patterns on a day-to-day basis.

![Cumulative usage toggle in the Billable metrics section](https://res.cloudinary.com/dza7lstvk/image/upload/v1765976513/Cloud/CleanShot_2025-12-17_at_15.01.07_2x_aimjwh.png)

#### Understanding the Charts

In each chart, there are two line types:

1. Green lines: Represent your actual usage for the resource over time. This is the usage that has already occurred.
2. Grey lines: Represent the forecasted usage for the resource. This is an estimate of your future usage based on historical data.

There's also a horizontal orange dashed line indicating your plan's usage limit for that resource. If your actual usage (green line) exceeds this limit, the excess is considered Flex Usage.

If your organization has [credits](#view-organization-credits) for a resource, the cumulative chart of that resource also shows a yellow dashed line indicating the combined allowance of your plan and credits. In this case, the chart's tooltip shows the plan's allowance and the combined allowance separately, along with the **Credited** quantity.

## Download Cloud Usage Report

To download your organization's usage as a JSON file:

1. Make sure you're viewing the [correct organization's dashboard in Cloud](../organizations/page.mdx#switch-organization).
2. Click **Usage** in the sidebar to open the organization's usage settings.
3. Click the <InlineIcon Icon={ArrowDownTray} alt="download" /> button at the top right.

The JSON file will be downloaded automatically.

---

## View Usage for Different Date Ranges

By default, the usage table and Flex Usage chart show data for the current billing cycle on Cloud.

To view usage for a different billing cycle, click on the "Current billing cycle" dropdown at the top of the Usage settings. You can then select the previous billing cycle, or a custom date range.

After making your selection, the usage table will update automatically after a few seconds.

![Usage table updated for different billing cycle](https://res.cloudinary.com/dza7lstvk/image/upload/v1755266925/Cloud/CleanShot_2025-08-15_at_17.07.47_2x_ieqxwi.png)

## Filter Usage by Project

You can filter usage data by project using the project dropdown at the top of the Usage settings. The dropdown lists all projects in your organization, including deleted ones. Deleted projects appear with a **Deleted** badge next to their name, and active projects are sorted before deleted ones.

To filter usage by a specific project:

1. Make sure you're viewing the [correct organization's dashboard in Cloud](../organizations/page.mdx#switch-organization).
2. Click **Usage** in the sidebar to open the organization's usage settings.
3. Click the "all projects" filter dropdown.
4. Select the project whose usage you want to view, including deleted projects if needed.

The usage table and charts update to show data only for the selected project.
