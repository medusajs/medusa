## Webhooks Overview

A webhook is an HTTP request that Cloud sends to an endpoint you own when something happens in your organization, such as a deployment finishing. Webhooks let you react to changes in Cloud without polling its APIs.

Cloud sends every webhook as a `POST` request with a JSON body. Your endpoint must return a `2xx` status code to acknowledge the delivery.

<Note>

Refer to the [Webhooks Changelog](./changelog/page.mdx) for dated updates to the webhook events that Cloud delivers.

</Note>

### Verify a Signature

Compute the HMAC SHA-256 of the raw request body using your endpoint's secret, then compare it to the `X-Medusa-Signature` header:

```ts
import crypto from "crypto"

export function isValid(
  rawBody: string,
  signature: string,
  secret: string
) {
  const expected = crypto
    .createHmac("sha256", secret)
    .update(rawBody)
    .digest("hex")

  return crypto.timingSafeEqual(
    Buffer.from(expected),
    Buffer.from(signature)
  )
}
```

Verify the signature against the raw request body. If your framework parses the body into an object first, the signature won't match.

### Retries

If your endpoint doesn't return a `2xx` status code, Cloud retries the delivery with an exponential backoff. Cloud stops retrying after the last attempt fails, and the delivery is marked as failed.

## deployment.succeeded

Cloud sends this event when a deployment of an environment finishes successfully.

### Payload

<TypeList
  types={[
    {
      name: "event",
      type: "`string`",
      description: `The name of the event. Always \`deployment.succeeded\`.`,
    },
    {
      name: "created_at",
      type: "`string`",
      description: `The date and time the event occurred, in ISO 8601 format.`,
    },
    {
      name: "data",
      type: "`object`",
      description: `The details of the deployment.`,
      children: [
        {
          name: "id",
          type: "`string`",
          description: `The ID of the deployment.`,
        },
        {
          name: "environment_id",
          type: "`string`",
          description: `The ID of the environment the deployment belongs to.`,
        },
        {
          name: "project_id",
          type: "`string`",
          description: `The ID of the project the deployment belongs to.`,
        },
        {
          name: "commit_sha",
          type: "`string`",
          description: `The SHA of the commit that triggered the deployment.`,
        },
      ],
    },
  ]}
  sectionTitle="deployment.succeeded"
/>

### Example Payload

```json
{
  "event": "deployment.succeeded",
  "created_at": "2026-08-04T10:12:31.000Z",
  "data": {
    "id": "depl_01J8Z",
    "environment_id": "env_01J8Z",
    "project_id": "proj_01J8Z",
    "commit_sha": "9f2c1ab"
  }
}
```
