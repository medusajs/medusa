### Delivery

Cloud delivers webhooks via HTTP POST with a 10-second timeout per attempt. Failed deliveries are retried automatically using exponential back-off starting at 5 minutes, doubling with each attempt, for up to 24 hours. Each request includes the headers X-Medusa-Signature (an HMAC-SHA256 signature of the form t=<timestamp>,v1=<hex> for verifying authenticity), X-Medusa-Event (the event type), X-Medusa-Delivery (the unique delivery ID), and User-Agent: MedusaCloud-Webhook/1.0. The signature is computed over <timestamp>.<raw JSON body> using the endpoint secret. Redirects are not followed.
