In this guide, you'll learn how to connect ChatGPT to the Medusa MCP server and use it to ask questions about your Cloud stores.

## What is the Medusa ChatGPT Plugin?

The ChatGPT plugin connects ChatGPT to the [Medusa MCP server](../page.mdx), so you can ask ChatGPT questions about your stores' orders, products, customers, and other commerce data.

The ChatGPT plugin is read-only. ChatGPT can retrieve data from your stores, but it can't create, update, or delete data.

The ChatGPT plugin uses the Medusa MCP server's [static mode](../page.mdx#static-mode), so ChatGPT can only call a fixed set of tools that retrieve common commerce data, such as orders, products, and customers. If you want ChatGPT to access all of your store's API routes, including your custom API routes, [add the Medusa MCP server as a custom plugin](#add-medusa-mcp-as-a-custom-plugin-in-chatgpt) instead.

<Note>

The Medusa MCP server is in beta access. If an environment's latest build is from before October 8, 2026, rebuild it before you connect it to ChatGPT, as explained in the [Medusa MCP](../page.mdx#step-1-rebuild-environments) guide.

</Note>

## Add the Medusa Plugin to ChatGPT

To add the ChatGPT plugin:

1. Open the [Medusa plugin in ChatGPT](https://chatgpt.com/plugins/plugin_asdk_app_6aed956ee81c81919f9ade97457321f1). Alternatively, click **Plugins** in ChatGPT's sidebar, then search for `Medusa` and select the plugin.
2. Click **Install Plugin**.
3. In the browser window that opens, log in to your Cloud account.
4. On the consent page, select the environments that ChatGPT can access, then click **Approve**.

Refer to the [Medusa MCP](../page.mdx#approve-the-connection) guide for more details on the consent page.

<Note>

On ChatGPT Business and Enterprise plans, a workspace admin may need to enable the ChatGPT plugin before members can connect to it.

</Note>

## Add Medusa MCP as a Custom Plugin in ChatGPT

The ChatGPT plugin only provides the Medusa MCP server's [static tools](../page.mdx#static-mode). To use all of the Medusa MCP server's tools in ChatGPT, such as the tools that find and call your store's custom API routes, add the Medusa MCP server to ChatGPT as a custom plugin instead. This requires enabling developer mode in ChatGPT.

To add the Medusa MCP server as a custom plugin:

1. In ChatGPT, go to **Settings** > **Security and login**, then turn on **Developer mode**.
2. Click **Plugins** in the sidebar, then click the plus button.
3. Enter a name, such as `Medusa`, and an optional description.
4. Under **Connection**, enter the URL `https://cloud.medusajs.com/mcp` and choose OAuth authentication.
5. Create the plugin, then connect it and log in to your Cloud account.
6. On the consent page, select the environments that ChatGPT can access, then click **Approve**.

Refer to [OpenAI's documentation](https://developers.openai.com/plugins/deploy/connect-chatgpt) for more details on developer mode and custom plugins.

<Note>

Developer mode's availability depends on your ChatGPT plan and workspace settings. On Business and Enterprise plans, a workspace admin may need to allow developer mode.

</Note>

## Use Medusa in ChatGPT

Once you add the plugin, select it from the tools menu in the message input, or mention it in your message. Then, ask ChatGPT questions about your stores. For example:

- "Which Medusa stores do I have connected?"
- "Show me the 5 most recent orders in my store, with each order's total and status."
- "How many orders are waiting to be fulfilled?"
- "How much stock is left for the SKU `SHIRT-S-BLACK`?"

Refer to the [Medusa MCP](../page.mdx#static-mode) guide for the list of tools that the ChatGPT plugin can call. If you added the Medusa MCP server as a custom plugin, ChatGPT can call all of the [available tools](../page.mdx#available-tools).

---

## Remove Medusa from ChatGPT

To remove the Medusa plugin from ChatGPT:

1. In ChatGPT, click **Plugins** in the sidebar.
2. Select the Medusa plugin and click **Disconnect**.

To change the stores that ChatGPT can access, disconnect the plugin and connect it again, then select the environments on the consent page.
