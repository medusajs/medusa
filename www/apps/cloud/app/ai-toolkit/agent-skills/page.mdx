# {metadata.title}

Medusa provides [agent skills](https://github.com/medusajs/medusa-agent-skills) that help developers and non-technical shop owners build stores, get development help, and learn Medusa interactively. Use them as plugins in Claude Code, or copy them into other AI tools that support custom skills.

## Deployment and Management Skills

To have your AI agent deploy, manage, and debug your Medusa projects, install the `medusa-cloud` plugin. Its skills teach your agent to use the [Cloud CLI](../../cli/agents/page.mdx):

<CodeTabs group="agent-skills">
  <CodeTab label="Claude Code" value="claude-code">

```bash
claude # start claude code
/plugin marketplace add medusajs/medusa-agent-skills
/plugin install medusa-cloud@medusa
```

  </CodeTab>
  <CodeTab label="Other AI Agents" value="skills-command">

```bash
npx skills add medusajs/medusa-agent-skills
# choose the following skill:
# - using-medusa-cloud
```

  </CodeTab>
</CodeTabs>

Then, ask your agent to manage your projects and environments. For example:

```bash title="Example Prompts"
Why did my latest deployment fail? Check its build logs.
Add the STRIPE_API_KEY environment variable to my Production environment.
```

## Medusa Development Assistance Skills

For help building features with Medusa, install the `medusa-dev` plugin:

<CodeTabs group="agent-skills">
  <CodeTab label="Claude Code" value="claude-code">

```bash
claude # start claude code
/plugin marketplace add medusajs/medusa-agent-skills
/plugin install medusa-dev@medusa
```

  </CodeTab>
  <CodeTab label="Other AI Agents" value="skills-command">

```bash
npx skills add medusajs/medusa-agent-skills
# choose the following skills:
# - building-with-medusa
# - building-admin-dashboard-customizations
# - building-storefronts
# - db-generate
# - db-migrate
# - new-user
```

  </CodeTab>
</CodeTabs>

Then, ask your agent to build Medusa features, fix bugs, and more. It uses the plugin's skills to write accurate Medusa code. For example:

```bash title="Example Prompts"
Implement a product reviews feature. Authenticated customers can add reviews. Admin users can view and approve or reject reviews from the dashboard
Create a wishlist feature where customers can save products. I need API routes for adding/removing items and retrieving the wishlist.
Add a widget to the product detail page in the admin that allows managing related products. Admin users should be able to select which products are related using a searchable table.
Help me integrate the custom reviews API into my Next.js storefront. Show product reviews on the product detail page with pagination.
```

## Ecommerce Storefront Best Practices

The `ecommerce-storefront` plugin's `storefront-best-practices` skill helps you build storefronts for any ecommerce platform, including Medusa, with any frontend framework, such as Next.js or Tanstack Start. Install it with:

<CodeTabs group="agent-skills">
  <CodeTab label="Claude Code" value="claude-code">

```bash
claude # start claude code
/plugin marketplace add medusajs/medusa-agent-skills
/plugin install ecommerce-storefront@medusa
```

  </CodeTab>
  <CodeTab label="Other AI Agents" value="skills-command">

```bash
npx skills add medusajs/medusa-agent-skills
# choose the following skill:
# - storefront-best-practices
```

  </CodeTab>
</CodeTabs>

Then, prompt your agent to change your storefront or build one from scratch. For example:

```bash title="Example Prompts"
Build a Next.js ecommerce storefront that uses Medusa as the backend. The storefront should have product listing, product detail, cart, and checkout pages.
Add a megamenu to the storefront's header that displays product categories and subcategories. The menu should be responsive and work well on mobile devices.
```

## Interactive Learning

If you're new to Medusa, install the `learn-medusa` plugin or its skill to learn the basics interactively:

<CodeTabs group="agent-skills">
  <CodeTab label="Claude Code" value="claude-code">

```bash
claude # start claude code
/plugin marketplace add medusajs/medusa-agent-skills
/plugin install learn-medusa@medusa
```

  </CodeTab>
  <CodeTab label="Other AI Agents" value="skills-command">

```bash
npx skills add medusajs/medusa-agent-skills
# choose the following skill:
# - learning-medusa
```

  </CodeTab>
</CodeTabs>

Then, start the learning experience with this prompt:

```bash title="Prompt"
I want to learn Medusa.
```

<Note title="Tip">

You can also run the skill using the `/learn-medusa:learning-medusa` command in Claude Code.

</Note>

You learn Medusa concepts step by step by building a brands feature, similar to the [Brands tutorial](!docs!/learn/customization/custom-features). You:

1. Create a Brand Module with API routes to manage brands.
2. Link brands to products to associate products with brands.
3. Customize the Medusa Admin dashboard to manage brands.

By the end, you understand Medusa's architecture and how to build custom features.
