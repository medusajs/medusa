## Docs Assistant

The Docs Assistant answers your questions and helps you build customizations with Medusa, with relevant documentation links, code snippets, and explanations.

### Open the Docs Assistant

To open the Docs Assistant, either:

- Use the keyboard shortcut <Kbd>Ctrl + I</Kbd> for Windows/Linux, or <Kbd>Cmd + I</Kbd> for macOS.
- Click the <InlineIcon Icon={DocsAssistantIcon} alt="Docs Assistant" /> icon in the top right corner of the documentation.

Then, ask any question about Medusa, such as:

- What is a workflow?
- How to create a product review module?
- How to update Medusa?
- How to fix this error?

### Ask About Code Snippets

Click the <InlineIcon Icon={DocsAssistantIcon} alt="Docs Assistant" /> icon in a code snippet's header to ask the Docs Assistant about it. The Docs Assistant explains the code and gives usage examples.

### Ask About Documentation Pages

Click the "Explain this page" link in a page's right sidebar to open the Docs Assistant with that page as context, then ask questions about its content.

### Formatting and Code Blocks

Wrap code blocks in your questions in triple backticks (```). For example:

~~~markdown
```
console.log("Hello, World!")
```
~~~

Add new lines with `Shift + Enter`.

## Docs SKILL.md

The docs `SKILL.md` at [https://docs.medusajs.com/SKILL.md](https://docs.medusajs.com/SKILL.md) is an [agent skill](https://agentskills.io) that tells AI agents how to navigate the Medusa documentation, where to find what, and which tools they can use to read it.

Ask your agent to fetch it before working on a Medusa task:

```bash title="Prompt"
Fetch https://docs.medusajs.com/SKILL.md and use it to find the Medusa documentation you need
```

Since the [agent skills index](https://docs.medusajs.com/.well-known/agent-skills/index.json) lists it, you can also install it alongside the other [Medusa agent skills](../agent-skills/page.mdx).

## Markdown Pages and llms.txt

The Medusa documentation is available in Markdown and plain text formats for LLMs and AI tools:

- [llms.txt](https://docs.medusajs.com/llms.txt): An index of the documentation that links to the index of each documentation section, such as [Get Started](https://docs.medusajs.com/cloud/llms.txt) and [Development Resources](https://docs.medusajs.com/resources/llms.txt).
- [llms-full.txt](https://docs.medusajs.com/llms-full.txt): The full content of the Framework documentation in a single file.
- **Markdown version of any page**: Get any page as Markdown by either:
    - Sending an `Accept: text/markdown` header when requesting documentation pages. Agents like Claude Code send this header automatically.
    - Appending `.md` to the page URL. For example, [https://docs.medusajs.com/cloud/ai-toolkit/ai-friendly-docs.md](https://docs.medusajs.com/cloud/ai-toolkit/ai-friendly-docs.md).
    - Appending `/index.html.md` to the page URL. For example, [https://docs.medusajs.com/cloud/ai-toolkit/ai-friendly-docs/index.html.md](https://docs.medusajs.com/cloud/ai-toolkit/ai-friendly-docs/index.html.md).

## Docs Retrieval Endpoint

The retrieval endpoint returns the most relevant documentation content for a query, without generating an answer. Agents use it to find the right documentation before writing code.

Send a `GET` request with your query in the `q` parameter:

```bash
curl "https://docs.medusajs.com/agents/ask?q=how+to+create+a+workflow"
```

Query parameters:

- `q`: (required) The question or keywords to search for, up to 500 characters.
- `limit`: (optional) The number of results to return, from `1` to `15`. Defaults to `5`.
- `agent`: (optional) The name of the agent sending the request, such as `Claude Code`. Medusa uses it to improve the docs for that agent.

It returns a JSON object like the following:

```json
{
  "query": "how to create a workflow",
  "results": [
    {
      "url": "https://docs.medusajs.com/learn/fundamentals/workflows",
      "content": "# Workflows\n\n..."
    }
  ]
}
```

To get the results as Markdown instead, send the `Accept: text/markdown` header. You can also send a `POST` request with a JSON body `{ "query": "...", "limit": 5, "agent": "..." }`.

## WebMCP Tools

[WebMCP](https://github.com/webmachinelearning/webmcp) lets websites expose tools that browser AI agents can call. Every Medusa documentation page registers the following WebMCP tools, so agents in a supporting browser can use the docs without scraping:

- `search_medusa_docs`: Search the documentation using the [retrieval endpoint](#docs-retrieval-endpoint).
- `get_medusa_docs_page`: Get the Markdown content of a documentation page by its URL or path.
- `navigate_medusa_docs`: Open a documentation page by its URL or path.

## Discovery Endpoints

Agents and tools can discover the documentation's agent-facing resources programmatically under the `.well-known` path:

- [/.well-known/ai-catalog.json](https://docs.medusajs.com/.well-known/ai-catalog.json): A catalog of all agent-facing resources, including the docs `SKILL.md`, the retrieval endpoint, the Docs MCP server, agent skills, and API specifications.
- [/.well-known/agent-skills/index.json](https://docs.medusajs.com/.well-known/agent-skills/index.json): An index of the docs `SKILL.md` and the [Medusa agent skills](../agent-skills/page.mdx).
- [/.well-known/mcp/server-card.json](https://docs.medusajs.com/.well-known/mcp/server-card.json): The [Docs MCP server's](../docs-mcp/page.mdx) metadata.
- [/.well-known/api-catalog](https://docs.medusajs.com/.well-known/api-catalog): Links to the Store and Admin API OpenAPI specifications, the Docs MCP server, and the retrieval endpoint.

The documentation homepage also links these resources in its `Link` response header.
