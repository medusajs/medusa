## Files Not Found After Deployment

Before deploying your Medusa application on Cloud, Medusa runs the `build` script defined in your `package.json` file, then copies only the output of the [build process](!docs!/learn/build), which is the `.medusa/server` directory.

The `.medusa/server` directory holds the compiled JavaScript files of your project, the production build of the admin dashboard, and other necessary files to run your Medusa application in production.

If you have custom files needed at runtime, such as a `src/data` directory that holds JSON files, modify the `build` script in your `package.json` file to copy these files to the `.medusa/server` directory after the build process.

For example:

```json title="package.json"
{
  "scripts": {
    "postbuild": "cp -r src/data .medusa/server/src/data",
    "build": "medusa build && npm run postbuild"
  }
}
```

This script copies the `src/data` directory to the `.medusa/server` directory following the build process.

Learn more in the [Deployments Guide](../page.mdx#build-process-for-deployments).

<Note>

You can replace `npm run postbuild` with the appropriate command for your package manager, such as `yarn postbuild`.

</Note>

## AI Support Agent for Failed Deployments

When a deployment fails during the build or deployment process, Cloud provides an AI support agent to help diagnose and resolve the issue.

The AI support agent button appears in the deployment activity section header when:

- A build fails (status: "Build failed")
- A deployment fails (status: "Deploy failed")

To use the AI support agent:

1. [Navigate to the failed deployment's details page](../page.mdx#find-deployment-details).
2. In the Activity section, look for the AI support agent button in the section header.
3. Click the button to open the AI assistant.

The AI assistant will automatically ask contextual questions based on the type of failure:

- For build failures: "Why did my build fail and how can I fix it?"
- For deployment failures: "Why did my deployment fail and how can I fix it?"

The AI support agent analyzes your deployment logs and provides tailored suggestions to help resolve the specific issue you're encountering.

<Note>

The AI support agent feature may not be available for all users as it's currently being rolled out gradually.

</Note>
