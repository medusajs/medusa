# {metadata.title}

In this guide, you'll learn how to monitor your environment's performance using Cloud's monitoring dashboard.

<Note>

Environment monitoring is currently in preview and may not be available for all users. The feature is gradually being rolled out to all organizations.

</Note>

## Monitoring Overview

The Environment Monitoring section provides comprehensive insights into your deployed application's performance across multiple areas:

- **Servers**: Monitor CPU usage, memory consumption, and server restarts
- **Workers**: Track worker instance performance and resource utilization  
- **Database**: View database performance metrics (coming soon)
- **HTTP**: Monitor HTTP request patterns and response metrics (coming soon)

## Access Environment Monitoring

To access monitoring for your environment:

1. Go to your project's dashboard in Cloud.
2. Click on the environment card you want to monitor.
3. Click the **Monitoring** tab in the environment navigation.

The Monitoring section appears as a fourth tab alongside Overview, Logs, and Settings.

## Monitoring Sections

### Servers Monitoring

The Servers page displays four key metric cards with interactive charts:

- **Total CPU**: Area chart showing allocated vs used CPU resources
- **Per Instance CPU**: Line chart with minimum, maximum, and average CPU percentages
- **Per Instance Memory**: Line chart with minimum, maximum, and average memory percentages  
- **Restarts**: Bar chart showing server restart frequency

### Workers Monitoring

The Workers page provides the same metrics as servers, specifically focused on worker instances:

- **Total CPU**: Worker CPU allocation and usage
- **Per Instance CPU**: Worker CPU performance across instances
- **Per Instance Memory**: Worker memory utilization patterns
- **Restarts**: Worker restart frequency and patterns

### Database Monitoring

Database monitoring metrics are coming soon and will provide insights into database performance and resource usage.

### HTTP Monitoring

HTTP monitoring metrics are coming soon and will track request patterns, response times, and HTTP-related performance data.

## Time Range Controls

Use the time range selector in the top right corner to adjust your monitoring view:

### Available Time Ranges

Time range options vary based on your subscription plan:

- **Hobby/Develop plans**: 1 hour, 6 hours, 24 hours
- **Launch/Scale plans**: 1 hour, 6 hours, 12 hours, 1 day, 3 days, 7 days

### Refresh Data

Click the refresh button next to the time range selector to update the monitoring data with the latest metrics.

## Chart Interactions

All monitoring charts include:

- **Tooltips**: Hover over chart elements to see detailed values
- **Time-based visualization**: View metrics across your selected time range
- **Interactive navigation**: Click and drag to zoom into specific time periods
