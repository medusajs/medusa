In this guide, you'll learn about HTTP request and response monitoring for your Cloud environments.

<Note>

HTTP monitoring is currently in development and will be available soon. This page will be updated with detailed monitoring features once they become available.

</Note>

## Coming Soon

HTTP monitoring features are being developed and will include:

- **Request metrics**: Track HTTP request volume, patterns, and response times
- **Response analysis**: Monitor HTTP response codes and error rates
- **API endpoint performance**: View performance metrics for specific API endpoints
- **Traffic patterns**: Analyze request traffic over time

## Access HTTP Monitoring

Once available, you'll be able to access HTTP monitoring by:

1. Going to your project's dashboard in Cloud
2. Clicking on the environment card you want to monitor
3. Clicking the **Monitoring** tab
4. Selecting **HTTP** from the monitoring sidebar

## Stay Updated

HTTP monitoring features are being actively developed. Check back for updates as new monitoring capabilities become available.
