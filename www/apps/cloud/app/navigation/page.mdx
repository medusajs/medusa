In this guide, you'll learn about how navigation works in the Cloud dashboard.

## Cloud Dashboard Navigation

The Cloud dashboard uses a global sidebar layout. The sidebar appears on the left side of every page and gives you access to all navigation options, including switching between projects, environments, deployments, logs, settings, and more.

The sidebar is always active and cannot be disabled.
