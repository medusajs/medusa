# Cloud Documentation

Next.js app for the Medusa Cloud docs, served under `/cloud`. Content is MDX
under `app/`, and the sidebar is `sidebar.mjs`. Load the `writing-docs` skill
before editing any MDX file.

## Changelog entries

Every user-visible dashboard change gets a dated entry in the Cloud changelog.

- Add a `generated/changelog/{YYYY-MM-DD}.mjs` file. Never add entries to
  `app/changelog/page.mdx`, and never edit `generated/changelog/index.mjs` by
  hand.
- Follow the entry format and rules in
  [`generated/changelog/README.md`](generated/changelog/README.md).
- After adding or changing an entry, run `yarn prep` in `www/apps/cloud` to
  regenerate `index.mjs`.

## Changelog banner images

Every entry gets a banner `image`, generated by the
[`release-banner`](../../utils/packages/release-banner) package's
`cloud-changelog` type and uploaded to Cloudinary. Never write the `image` URL
by hand or invent one.

The cloud docs automation workflow does this in CI. To do it locally:

```bash
# Build the CLI once
cd www/utils && yarn install && yarn workspace release-banner build

# Upload the banner. Run from the package directory so its `.env`
# (CLOUDINARY_URL) is loaded. The date is the entry's display date.
cd www/utils/packages/release-banner
BANNER_URL=$(node dist/cli.js upload \
  --type cloud-changelog --date "October 8, 2026")

# Patch the URL into the entry. Run from www/apps/cloud, since the
# script resolves `--date` against the current directory.
cd ../../../apps/cloud
node scripts/set-changelog-image.mjs \
  --date 2026-10-08 --url "$BANNER_URL"
```

- To check the banner before uploading, swap `upload` for `render` with
  `--out <path>.png` and open the file.
- The banner depends on the date alone, so entries sharing a date share a
  banner, and re-uploading overwrites it in place.

## What's New

When a Cloud feature or notable guide ships, also add it to the docs-wide What's
New list in `www/apps/book/components/Homepage/WhatsNewSection/data.ts` with the
`Medusa Cloud` tag. See [`www/apps/book/CLAUDE.md`](../book/CLAUDE.md) for the
entry format.
