# Set Up Medusa with AI Agents

Create an ecommerce store with Medusa and go live in minutes. This page is designed for AI agents and humans who want to get started quickly with an AI agent.

If you're a human, copy this prompt and run it in your AI agent:

```bash title="Prompt"
Fetch https://docs.medusajs.com/start and create an ecommerce store with Medusa Cloud
```

The AI agent will guide you through creating a store on [Cloud](!cloud!) from a starter or your existing Medusa application, and watch its deployment until it's live. Then, if you want to build custom commerce features, it can set up the project on your machine and help you build them.

## FAQ

### What does the prompt do?

The prompt instructs the AI agent to fetch this page. When the agent fetches it, it receives step-by-step instructions to set up Medusa.

The AI agent will then execute the instructions, which include signing you in to [Cloud](!cloud!), guiding you through creating and deploying your project, optionally setting it up locally, and providing next steps to build custom commerce features.

### Do I need a Cloud account?

Yes, your store is created and hosted on [Cloud](!cloud!). If you don't have an account, the AI agent helps you sign up.

### What steps do I perform myself?

The AI agent runs the commands in your terminal, such as installing the Cloud CLI, monitoring the deployment, and setting up the project locally.

Some steps happen in your browser, such as signing in to Cloud and creating the project from the Cloud dashboard. For those steps, the AI agent tells you exactly what to do and waits for you to confirm before it continues.

### Can I deploy an existing Medusa application?

Yes, tell the AI agent that you want to deploy an existing application instead of a starter. The application must be in a GitHub repository and meet the [project prerequisites](!cloud!/projects/prerequisites).

### Can my AI agent build custom features?

Yes, after setting up Medusa, your AI agent can help you build custom commerce features.

You can instruct your AI agent to implement specific functionalities, integrate third-party services, or build custom workflows using the Medusa Framework.

### Can I use my own domain?

Yes, you can [add custom domains](!cloud!/environments/custom-domains) to your Medusa store deployed on Cloud.
