# getOrderPendingAmountStep - Medusa Core Workflows Reference

This documentation provides a reference to the `getOrderPendingAmountStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step resolves an order's pending amount and validates the requested
charge against it. It throws an error if the amount to charge is greater than
the order's pending amount.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { getOrderPendingAmountStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = getOrderPendingAmountStep("{value}")
  }
)
```
