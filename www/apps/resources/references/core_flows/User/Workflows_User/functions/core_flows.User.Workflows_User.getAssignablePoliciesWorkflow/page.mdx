# getAssignablePoliciesWorkflow - Medusa Core Workflows Reference

:::note

To use this resource, make sure to [enable its feature flag: rbac](https://docs.medusajs.com/development/feature-flags/toggle)

:::

This documentation provides a reference to the `getAssignablePoliciesWorkflow`. It belongs to the `@medusajs/medusa/core-flows` package.

Returns the set of `rbac_policy` rows the actor is allowed to assign.

:::note

This is available starting from [Medusa v2.16.0](https://github.com/medusajs/medusa/releases/tag/v2.16.0).

:::
