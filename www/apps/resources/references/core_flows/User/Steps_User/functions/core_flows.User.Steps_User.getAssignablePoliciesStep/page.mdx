This documentation provides a reference to the `getAssignablePoliciesStep`. It belongs to the `@medusajs/medusa/core-flows` package.

Resolves the set of policies the actor is allowed to assign.

:::note

This is available starting from [Medusa v2.16.0](https://github.com/medusajs/medusa/releases/tag/v2.16.0).

:::
