# validateUserRolePermissionsStep - Medusa Core Workflows Reference

:::note

To use this resource, make sure to [enable its feature flag: rbac](https://docs.medusajs.com/development/feature-flags/toggle)

:::

This documentation provides a reference to the `validateUserRolePermissionsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

Validates that the actor has all the policies from the roles being assigned.
A user can only assign roles whose policies they themselves have.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { validateUserRolePermissionsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = validateUserRolePermissionsStep({})
  }
)
```
