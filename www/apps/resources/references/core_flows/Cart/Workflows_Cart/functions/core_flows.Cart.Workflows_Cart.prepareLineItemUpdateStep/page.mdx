# prepareLineItemUpdateStep - Medusa Core Workflows Reference

This documentation provides a reference to the `prepareLineItemUpdateStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step builds the update payload for a cart line item, resolving its unit
price (from the input, the variant's calculated price, or the existing item)
and tax inclusivity. It throws an error if the resulting unit price is unset.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { prepareLineItemUpdateStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = prepareLineItemUpdateStep("{value}")
  }
)
```
