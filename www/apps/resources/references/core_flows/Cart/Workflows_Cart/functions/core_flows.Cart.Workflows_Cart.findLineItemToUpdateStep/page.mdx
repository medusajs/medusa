# findLineItemToUpdateStep - Medusa Core Workflows Reference

This documentation provides a reference to the `findLineItemToUpdateStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step finds the line item to update in the cart and collects its variant
id. It throws an error if the line item isn't found in the cart.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { findLineItemToUpdateStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = findLineItemToUpdateStep("{value}")
  }
)
```
