# prepareCartToUpdateStep - Medusa Core Workflows Reference

This documentation provides a reference to the `prepareCartToUpdateStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step builds the cart update payload: it resolves the currency and region
from the (possibly new) region, reconciles the shipping address against the
region's countries, and applies customer and sales channel changes. It throws
an error if the shipping address country isn't within the region.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { prepareCartToUpdateStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = prepareCartToUpdateStep("{value}")
  }
)
```
