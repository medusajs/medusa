# addProductOptionsToProductStep - Medusa Core Workflows Reference

This documentation provides a reference to the `addProductOptionsToProductStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step adds product options to products.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { addProductOptionsToProductStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = addProductOptionsToProductStep({
      "product_option_id": "{value}",
      "product_id": "prod_123"
    })
  }
)
```
