# removeProductOptionsFromProductStep - Medusa Core Workflows Reference

This documentation provides a reference to the `removeProductOptionsFromProductStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step removes product options from products.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { removeProductOptionsFromProductStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = removeProductOptionsFromProductStep({
      "product_option_id": "{value}",
      "product_id": "prod_123"
    })
  }
)
```
