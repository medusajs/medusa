# updateProductOptionValuesOnProductStep - Medusa Core Workflows Reference

This documentation provides a reference to the `updateProductOptionValuesOnProductStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step updates product option values linked to products.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { updateProductOptionValuesOnProductStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = updateProductOptionValuesOnProductStep({
      "product_option_id": "{value}",
      "product_id": "prod_123"
    })
  }
)
```
