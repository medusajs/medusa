# linkOptions

This method links product options to a product. It allows adding new options,
removing existing ones, or updating option values. It sends a request to the
[Batch Product Product Options](https://docs.medusajs.com/api/admin#products\_postproductsidoptionsbatch)
API route.

:::note

This is available starting from [Medusa v2.16.0](https://github.com/medusajs/medusa/releases/tag/v2.16.0).

:::

## Example

```ts
sdk.admin.product.linkOptions("prod_123", {
  add: [
      "opt_123",
      {
        id: "opt_123",
        value_ids: ["optval_1", "optval_2"]
      }
    ],
    remove: ["opt_456"]
})
.then(({ product }) => {
  console.log(product)
})
```
