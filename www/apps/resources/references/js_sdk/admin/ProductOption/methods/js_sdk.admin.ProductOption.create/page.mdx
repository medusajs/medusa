# create

This method creates a product option. It sends a request to the
[Create Option](https://docs.medusajs.com/api/admin#product-options\_postproductoptions)
API route.

## Example

```ts
sdk.admin.productOption.create({
  title: "Size",
  values: ["S", "M"]
})
.then(({ product_option }) => {
  console.log(product_option)
})
```
