# AuthVerificationRequestPayload

Payload used to request a verification token.

:::note

This is available starting from [Medusa v2.15.5](https://github.com/medusajs/medusa/releases/tag/v2.15.5).

:::

## entity\_id

The provider identity to verify.

___

## entity\_type

The kind of entity being verified, such as `email` or `phone_number`.

___

## code\_provider

<BadgesList badges={[
  {
    "variant": "neutral",
    "children": "optional"
  }
]} className="mb-1" />

The verification provider to use. Defaults to `token`.
