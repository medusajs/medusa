# removeProductOptionFromProduct - Product Module Reference

This documentation provides a reference to the `removeProductOptionFromProduct` method. This belongs to the Product Module.

<Note>

You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/medusa-workflows-reference).

</Note>

## removeProductOptionFromProduct(productOptionProductPair, sharedContext?): Promise&#60;void&#62;

This method removes a product option from a product.

:::note

This is available starting from [Medusa v2.16.0](https://github.com/medusajs/medusa/releases/tag/v2.16.0).

:::

### Example

```ts
await productModuleService.removeProductOptionFromProduct({
  product_id: "prod_123",
  product_option_id: "opt_123",
})
```

## removeProductOptionFromProduct(productOptionProductPairs, sharedContext?): Promise&#60;void&#62;

:::note

This is available starting from [Medusa v2.16.0](https://github.com/medusajs/medusa/releases/tag/v2.16.0).

:::

### Example

```ts
await productModuleService.removeProductOptionFromProduct([
  {
    product_id: "prod_123",
    product_option_id: "opt_123",
  },
])
```
