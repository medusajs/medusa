# updateRbacRoles - RBAC Module Reference

<EnterpriseNotice featureName="role-based access control feature" featureFlag="rbac" featureFlagHref="/resources/commerce-modules/rbac#how-to-use-the-rbac-module" />

This documentation provides a reference to the `updateRbacRoles` method. This belongs to the RBAC Module.

<Note>

You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/medusa-workflows-reference).

</Note>

## updateRbacRoles(data, sharedContext?): Promise&#60;[RbacRoleDTO](../../../types/rbac.RbacRoleDTO/page.mdx)&#62;

This method updates an existing role.

### Example

```ts
const role = await rbacModuleService.updateRbacRoles({
  id: "rbrole_123",
  name: "Admin",
})
```
