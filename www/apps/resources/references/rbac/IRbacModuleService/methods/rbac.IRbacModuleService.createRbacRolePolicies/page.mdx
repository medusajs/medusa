# createRbacRolePolicies - RBAC Module Reference

<EnterpriseNotice featureName="role-based access control feature" featureFlag="rbac" featureFlagHref="/resources/commerce-modules/rbac#how-to-use-the-rbac-module" />

This documentation provides a reference to the `createRbacRolePolicies` method. This belongs to the RBAC Module.

<Note>

You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/medusa-workflows-reference).

</Note>

## createRbacRolePolicies(data, sharedContext?): Promise&#60;[RbacRolePolicyDTO](../../../types/rbac.RbacRolePolicyDTO/page.mdx)&#62;

This method creates a role-policy assignment, associating a policy with a role.

### Example

```ts
const rolePolicy = await rbacModuleService.createRbacRolePolicies({
  role_id: "rbrole_123",
  policy_id: "rbpol_123",
})
```
