# IRbacModuleService Reference

<EnterpriseNotice featureName="role-based access control feature" featureFlag="rbac" featureFlagHref="/resources/commerce-modules/rbac#how-to-use-the-rbac-module" />

This section of the documentation provides a reference to the `IRbacModuleService` interface’s methods. This is the interface developers use to use the functionalities provided by the RBAC Module.

<Note>

You should only use the methods in this reference when implementing complex customizations. For common cases, check out [available workflows instead](/medusa-workflows-reference).

</Note>

The main service interface for the RBAC Module.
