# {metadata.title}

Start the Medusa application in development.

This command watches files for any changes, then rebuilds the files and restarts the Medusa application.

<Note>

Since [Medusa v2.13.7](https://github.com/medusajs/medusa/releases/tag/v2.13.7), when you stop the development server (Ctrl+C), the command prompts you to install the Medusa Plugin for Claude Code if Claude Code is detected on your system and the plugin isn't already installed.

</Note>

```bash npx2yarn
npx medusa develop
```
