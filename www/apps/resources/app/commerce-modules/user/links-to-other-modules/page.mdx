## RBAC Module

<EnterpriseNotice featureFlag="rbac" featureFlagHref="../../rbac/page.mdx#how-to-use-the-rbac-module" />

You assign roles to admin users to control their access. Medusa defines a link between the `User` data model and the `RbacRole` data model from the [RBAC Module](../../rbac/page.mdx).

An admin user can have multiple roles, and a role can be assigned to multiple users. The user's effective policies are the union of the policies from all their assigned roles.

### Retrieve with Query

To retrieve the roles of a user with [Query](!docs!/learn/fundamentals/module-links/query), pass `rbac_roles.*` in `fields`:

<CodeTabs group="relation-query">
  <CodeTab label="query.graph" value="method">

```ts
const { data: users } = await query.graph({
  entity: "user",
  fields: [
    "rbac_roles.*",
  ],
})

// users[0].rbac_roles
```

  </CodeTab>
  <CodeTab label="useQueryGraphStep" value="step">

```ts
import { useQueryGraphStep } from "@medusajs/medusa/core-flows"

// ...

const { data: users } = useQueryGraphStep({
  entity: "user",
  fields: [
    "rbac_roles.*",
  ],
})

// users[0].rbac_roles
```

  </CodeTab>
</CodeTabs>

You can also retrieve the users of a role by passing `users.*` in `fields` when querying the `rbac_role` entity.

### Manage with Link

To assign a role to a user, use [Link](!docs!/learn/fundamentals/module-links/link):

<CodeTabs group="relation-link">
  <CodeTab label="link.create" value="method">

```ts
import { Modules } from "@medusajs/framework/utils"

// ...

await link.create({
  [Modules.USER]: {
    user_id: "user_123",
  },
  [Modules.RBAC]: {
    rbac_role_id: "role_123",
  },
})
```

  </CodeTab>
  <CodeTab label="createRemoteLinkStep" value="step">

```ts
import { Modules } from "@medusajs/framework/utils"
import { createRemoteLinkStep } from "@medusajs/medusa/core-flows"

// ...

createRemoteLinkStep([
  {
    [Modules.USER]: {
      user_id: "user_123",
    },
    [Modules.RBAC]: {
      rbac_role_id: "role_123",
    },
  },
])
```

  </CodeTab>
</CodeTabs>
