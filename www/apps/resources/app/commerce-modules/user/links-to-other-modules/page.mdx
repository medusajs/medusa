## RBAC Module

<EnterpriseNotice />

You assign roles to admin users to control their access. Medusa stores each of these grants as an `RbacRoleAssignment` record in the [RBAC Module](../../../enterprise/rbac/page.mdx), then exposes the roles of an admin user or an invite through read-only links.

An admin user can have multiple roles, and a role can be assigned to multiple users. The user's effective policies are the union of the policies from all their unscoped role assignments. A scoped assignment only adds its role's policies to requests within that scope.

### Retrieve with Query

To retrieve the roles of a user with [Query](!docs!/learn/fundamentals/query), pass `rbac_roles.*` in `fields`:

<CodeTabs group="relation-query">
  <CodeTab label="query.graph" value="method">

```ts
const { data: users } = await query.graph({
  entity: "user",
  fields: [
    "rbac_roles.*",
  ],
})

// users[0].rbac_roles
```

  </CodeTab>
  <CodeTab label="useQueryGraphStep" value="step">

```ts
import { useQueryGraphStep } from "@medusajs/medusa/core-flows"

// ...

const { data: users } = useQueryGraphStep({
  entity: "user",
  fields: [
    "rbac_roles.*",
  ],
})

// users[0].rbac_roles
```

  </CodeTab>
</CodeTabs>

The `rbac_roles` field doesn't include the scope of each assignment. To retrieve it, pass `user_role_assignments.*` in `fields` instead.

To find the users a role is assigned to, query the `rbac_role_assignment` entity and filter by the role's ID and by `reference: "user"`.

### Manage Role Assignments

To assign a role to an admin user, use the `assignRolesWorkflow`:

```ts
import {
  assignRolesWorkflow,
} from "@medusajs/medusa/core-flows"

await assignRolesWorkflow(container).run({
  input: {
    assignments: [
      {
        role_id: "role_123",
        reference: "user",
        reference_id: "user_123",
      },
    ],
    granting_actor_id: "user_456",
  },
})
```

To remove a role from an admin user, use the `unassignRolesWorkflow` with the same input shape.

### Invite Roles

An invite can grant roles to the admin user created when someone accepts the invite. Medusa stores these grants as `RbacRoleAssignment` records whose `reference` is `invite`.

To retrieve the roles of an invite with [Query](!docs!/learn/fundamentals/query), pass `rbac_roles.*` in `fields`:

```ts
const { data: invites } = await query.graph({
  entity: "invite",
  fields: [
    "rbac_roles.*",
  ],
})

// invites[0].rbac_roles
```

To set an invite's roles when you create it, pass the `roles` parameter to the [Create Invite](!api!/admin#invites_postinvites) API route, as explained in the [RBAC API Routes](../../../enterprise/rbac/api-routes/page.mdx#assign-roles-to-invites) guide.

Learn more in the [RBAC Module's links documentation](../../../enterprise/rbac/links-to-other-modules/page.mdx#user-module).
