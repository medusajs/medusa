The Loyalty Plugin provides gift card and store credit functionality for your Medusa application. It includes two main modules that work together to provide comprehensive loyalty and retention features for your ecommerce store.

<Note>

Learn more about why modules are isolated in [this documentation](!docs!/learn/fundamentals/modules/isolation).

</Note>

## Loyalty Features

### Gift Cards
- **Gift Card Products**: Create physical or digital gift cards as products that customers can purchase
- **Gift Card Management**: Issue, redeem, and track gift cards with unique codes
- **Cart Integration**: Apply gift cards as payment during checkout
- **Admin Interface**: Complete admin UI for managing gift cards and their lifecycle

### Store Credit
- **Store Credit Accounts**: Create and manage customer store credit accounts
- **Credit Transactions**: Credit and debit operations with full transaction history
- **Balance Tracking**: Real-time balance calculation and reporting
- **Cart Integration**: Apply store credits as payment during checkout

## How to Use the Loyalty Plugin

The Loyalty Plugin is built using Medusa's modular architecture. You interact with it through [Workflows](!docs!/learn/fundamentals/workflows), which are special functions composed of a series of steps that guarantee data consistency and reliable roll-back mechanisms.

### Install the Plugin

First, install the loyalty plugin:

```bash npm2yarn
npm install @medusajs/loyalty-plugin
```

Then, add it to your `medusa-config.js`:

```js title="medusa-config.js"
module.exports = defineConfig({
  // ... other configurations
  plugins: [
    {
      resolve: `@medusajs/loyalty-plugin`,
    },
    // ... other plugins
  ],
})
```

### Example: Creating a Gift Card

You can use the built-in workflows to manage gift cards:

```ts title="src/workflows/create-custom-gift-card.ts" highlights={highlights}
import { 
  createWorkflow, 
  WorkflowResponse,
  createStep,
  StepResponse,
} from "@medusajs/framework/workflows-sdk"
import { createGiftCardsWorkflow } from "@medusajs/loyalty-plugin/workflows"

export const createCustomGiftCardWorkflow = createWorkflow(
  "create-custom-gift-card",
  () => {
    const { giftCards } = createGiftCardsWorkflow()

    return new WorkflowResponse({
      giftCards,
    })
  }
)
```

You can then execute the workflow in your custom API routes, scheduled jobs, or subscribers:

## Built-in Loyalty Workflows

The Loyalty Plugin provides built-in workflows for both gift cards and store credit management:

### Gift Card Workflows

- `createGiftCardsWorkflow` - Create new gift cards
- `updateGiftCardsWorkflow` - Update existing gift cards
- `deleteGiftCardWorkflow` - Delete gift cards
- `redeemGiftCardWorkflow` - Redeem gift cards for payment
- `claimGiftCardWorkflow` - Claim gift cards by code

### Store Credit Workflows

- `createStoreCreditAccountsWorkflow` - Create new store credit accounts
- `creditStoreCreditAccountWorkflow` - Add credit to accounts
- `debitAccountsWorkflow` - Debit from accounts
- `claimStoreCreditAccountWorkflow` - Claim store credit by code

### Cart Integration Workflows

- `addGiftCardToCartWorkflow` - Apply gift cards to carts
- `addStoreCreditToCartWorkflow` - Apply store credit to carts
- `confirmCartCreditLinesWorkflow` - Confirm credit lines during checkout

For detailed workflow references, see the [Loyalty Workflows Reference](!resources!/commerce-modules/loyalty/workflows).

## API Routes

The Loyalty Plugin provides comprehensive API routes for both admin and storefront use:

### Admin API Routes
- `/admin/gift-cards` - Manage gift cards
- `/admin/store-credit-accounts` - Manage store credit accounts
- `/admin/store-credit-accounts/{id}/credit` - Credit operations
- `/admin/store-credit-accounts/{id}/transactions` - Transaction history

### Store API Routes
- `/store/gift-cards/{code}` - Retrieve gift card by code
- `/store/store-credit-accounts` - Customer store credit accounts
- `/store/carts/{id}/gift-cards` - Apply gift cards to cart
- `/store/carts/{id}/store-credits` - Apply store credits to cart
