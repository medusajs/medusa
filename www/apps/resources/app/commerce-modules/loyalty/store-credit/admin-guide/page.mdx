# {metadata.title}

In this document, you'll learn how to manage store credit accounts using admin APIs and workflows in the Loyalty Plugin.

## Prerequisites

Before using store credit functionality, ensure you have:
- Installed and configured the Loyalty Plugin
- Admin API access to your Medusa application  
- Understanding of [Medusa workflows](!docs!/learn/fundamentals/workflows)

## Managing Store Credit Accounts

### Creating Store Credit Accounts

Use the built-in workflow to create store credit accounts:

```ts title="src/workflows/create-store-credit-accounts.ts"
import { createStoreCreditAccountsWorkflow } from "@medusajs/loyalty-plugin/workflows"

// Create an account for a specific customer
const { result } = await createStoreCreditAccountsWorkflow(container).run({
  input: {
    customer_id: "cust_123456789",
    currency_code: "usd",
    metadata: {
      created_by: "admin_user_123",
      reason: "welcome_bonus",
    },
  },
})

// Create multiple accounts
const { result } = await createStoreCreditAccountsWorkflow(container).run({
  input: [
    {
      customer_id: "cust_123456789",
      currency_code: "usd",
    },
    {
      customer_id: "cust_987654321", 
      currency_code: "eur",
    },
  ],
})
```

### Using Admin API Routes

Create store credit accounts through the Admin API:

```http title="POST /admin/store-credit-accounts"
Content-Type: application/json

{
  "customer_id": "cust_123456789",
  "currency_code": "usd",
  "metadata": {
    "program": "loyalty_rewards",
    "tier": "gold"
  }
}
```

### Retrieving Store Credit Accounts

Get all store credit accounts:

```http title="GET /admin/store-credit-accounts"
GET /admin/store-credit-accounts?limit=20&offset=0

# Filter by customer
GET /admin/store-credit-accounts?customer_id=cust_123456789

# Filter by currency
GET /admin/store-credit-accounts?currency_code=usd
```

Get a specific account:

```http title="GET /admin/store-credit-accounts/{id}"
GET /admin/store-credit-accounts/sca_123456789
```

## Credit Operations

### Adding Credit to Accounts

Use the credit workflow to add funds to store credit accounts:

```ts title="Credit store credit account"
import { creditStoreCreditAccountWorkflow } from "@medusajs/loyalty-plugin/workflows"

const { result } = await creditStoreCreditAccountWorkflow(container).run({
  input: {
    account_id: "sca_123456789",
    amount: 5000, // $50.00 in cents
    reference: "refund",
    reference_id: "return_456",
    note: "Refund for returned item",
  },
})
```

Multiple accounts can be credited at once:

```ts title="Credit multiple accounts"
import { creditAccountsWorkflow } from "@medusajs/loyalty-plugin/workflows"

const { result } = await creditAccountsWorkflow(container).run({
  input: [
    {
      account_id: "sca_123456789",
      amount: 2500, // $25.00
      reference: "promotion",
      reference_id: "spring_campaign",
      note: "Spring promotion bonus",
    },
    {
      account_id: "sca_987654321",
      amount: 1000, // $10.00
      reference: "referral", 
      reference_id: "ref_bonus_001",
      note: "Referral bonus",
    },
  ],
})
```

### Using Admin API for Credits

Add credit through the API:

```http title="POST /admin/store-credit-accounts/{id}/credit"
Content-Type: application/json

{
  "amount": 5000,
  "reference": "customer_service",
  "reference_id": "ticket_789",
  "note": "Compensation for shipping delay"
}
```

### Debiting Accounts

Debit funds from store credit accounts:

```ts title="Debit store credit accounts"
import { debitAccountsWorkflow } from "@medusajs/loyalty-plugin/workflows"

const { result } = await debitAccountsWorkflow(container).run({
  input: [
    {
      account_id: "sca_123456789",
      amount: 1500, // $15.00
      reference: "order",
      reference_id: "order_456", 
      note: "Payment for order #456",
    },
  ],
})
```

<Note type="warning">

Debit operations will fail if the account doesn't have sufficient balance. The workflow automatically validates available balance before processing.

</Note>

## Balance Management

### Checking Account Balances

Account balances are automatically calculated from transaction history:

```ts title="Get account balance"
// Balance is included in account retrieval
const account = await fetch("/admin/store-credit-accounts/sca_123456789")
  .then((res) => res.json())

console.log(`Available balance: ${account.balance}`)
console.log(`Total credits: ${account.credits}`)  
console.log(`Total debits: ${account.debits}`)
```

### Balance Validation

Before debiting, validate sufficient balance:

```ts title="Balance validation example"
const validateBalance = async (accountId: string, debitAmount: number) => {
  const account = await fetch(`/admin/store-credit-accounts/${accountId}`)
    .then((res) => res.json())
  
  if (account.balance < debitAmount) {
    throw new Error(`Insufficient balance. Available: ${account.balance}, Required: ${debitAmount}`)
  }
  
  return true
}

// Use before debit operations
await validateBalance("sca_123456789", 2500)
```

## Integration with Orders and Returns

### Order Integration

Store credit can be applied during order processing:

```ts title="Apply store credit to orders"
// This typically happens automatically during checkout
// when customers select store credit as payment

// In order processing workflow
export const processOrderWithStoreCreditStep = createStep(
  "process-order-with-store-credit",
  async ({ order_id, store_credit_amount }, { container }) => {
    // Debit store credit account
    await debitAccountsWorkflow(container).run({
      input: [{
        account_id: order.customer.store_credit_account_id,
        amount: store_credit_amount,
        reference: "order",
        reference_id: order_id,
        note: `Payment for order ${order_id}`,
      }],
    })
    
    return new StepResponse({ success: true })
  }
)
```

### Return and Refund Integration

Credit accounts when processing returns:

```ts title="Refund to store credit"
// In return processing subscriber
export default async function handleReturnCompleted({
  event: { data },
  container,
}: SubscriberArgs<{ id: string }>) {
  const returnService = container.resolve("returnService")
  const returnOrder = await returnService.retrieve(data.id, {
    relations: ["order", "order.customer"],
  })

  // Credit customer's store credit account
  await creditStoreCreditAccountWorkflow(container).run({
    input: {
      account_id: returnOrder.order.customer.store_credit_account_id,
      amount: returnOrder.refund_amount,
      reference: "return",
      reference_id: data.id,
      note: `Refund for return ${data.id}`,
    },
  })
}

export const config: SubscriberConfig = {
  event: "return.completed",
}
```

## Bulk Operations

### Bulk Account Creation

Create multiple accounts for customer segments:

```ts title="Bulk account creation"
import { createStoreCreditAccountsWorkflow } from "@medusajs/loyalty-plugin/workflows"

// Get VIP customers
const vipCustomers = await fetch("/admin/customers?groups[]=vip")
  .then((res) => res.json())

// Create store credit accounts for all VIP customers
const accountData = vipCustomers.customers.map((customer) => ({
  customer_id: customer.id,
  currency_code: customer.default_currency || "usd",
  metadata: {
    tier: "vip",
    created_by: "bulk_operation",
    campaign: "vip_welcome",
  },
}))

const { result } = await createStoreCreditAccountsWorkflow(container).run({
  input: accountData,
})
```

Distribute credits to multiple accounts:

```ts title="Bulk credit distribution"
import { creditAccountsWorkflow } from "@medusajs/loyalty-plugin/workflows"

// Loyalty program rewards

  note: "Monthly loyalty bonus - Gold tier",
}))

const { result } = await creditAccountsWorkflow(container).run({
  input: creditData,
})
```

## Reporting and Analytics

### Account Balance Reports

Generate reports on store credit liability:

```ts title="Store credit reporting"
// Get all accounts with balances
const accounts = await fetch("/admin/store-credit-accounts")
  .then((res) => res.json())

// Calculate total liability and statistics
const report = {
  total_accounts: accounts.store_credit_accounts.length,
  total_liability: accounts.store_credit_accounts.reduce((sum, acc) => 
    sum + acc.balance, 0
  ),
  active_accounts: accounts.store_credit_accounts.filter((acc) => 
    acc.balance > 0
  ).length,
  average_balance: accounts.store_credit_accounts.reduce((sum, acc) => 
    sum + acc.balance, 0
  ) / accounts.store_credit_accounts.length,
}

console.log("Store Credit Report:", report)
```

### Transaction Analysis

Analyze store credit usage patterns:

```ts title="Transaction analysis"
// Get all transactions for analysis
const allTransactions = await Promise.all(
  accounts.store_credit_accounts.map((account) =>
    fetch(`/admin/store-credit-accounts/${account.id}/transactions`)
      .then((res) => res.json())
  )
)

const flatTransactions = allTransactions.flatMap((t) => t.transactions)

const analysis = {
  total_transactions: flatTransactions.length,
  credit_transactions: flatTransactions.filter((t) => t.type === "credit").length,
  debit_transactions: flatTransactions.filter((t) => t.type === "debit").length,
  top_references: Object.entries(
    flatTransactions.reduce((acc, t) => {
      acc[t.reference] = (acc[t.reference] || 0) + 1
      return acc
    }, {})
  ).sort(([,a], [,b]) => b - a).slice(0, 5),
}
```

## Best Practices

### Account Management
- Create accounts automatically when customers first receive credit
- Use meaningful metadata to track account purposes and sources
- Implement account status management for suspended or closed accounts
- Regular reconciliation of calculated balances

### Transaction Recording
- Always include reference and reference_id for audit trails
- Use descriptive notes for transaction clarity
- Implement proper error handling for failed debit operations
- Log all administrative actions for compliance

### Security and Validation
- Validate customer ownership before account operations
- Implement proper authorization for credit/debit operations
- Monitor for unusual account activity patterns
- Set reasonable limits on single transaction amounts

### Performance Considerations
- Index frequently queried fields (customer_id, currency_code)
- Use pagination for large transaction histories
- Consider caching frequently accessed account balances
- Optimize bulk operations for large customer segments
