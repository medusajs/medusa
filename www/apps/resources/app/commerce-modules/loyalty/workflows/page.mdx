# {metadata.title}

In this document, you'll find a reference for all workflows provided by the Loyalty Plugin.

The Loyalty Plugin provides comprehensive workflows for managing gift cards, store credit accounts, and cart integration. These workflows ensure data consistency and provide reliable rollback mechanisms for all loyalty operations.

## Gift Card Workflows

### createGiftCardsWorkflow

Creates one or more gift cards.

**Module**: `@medusajs/loyalty-plugin/workflows`

```ts title="Import"
import { createGiftCardsWorkflow } from "@medusajs/loyalty-plugin/workflows"
```

**Input Type**:
```ts title="Input Type"
type CreateGiftCardsWorkflowInput = {
  code?: string // Optional unique code, auto-generated if not provided
  amount: number // Amount in smallest currency unit (e.g., cents)
  currency_code: string // Three-letter currency code
  metadata?: Record<string, any> // Optional metadata
} | CreateGiftCardsWorkflowInput[]
```

**Example**:
```ts title="Usage Example"
// Create single gift card
const { result } = await createGiftCardsWorkflow(container).run({
  input: {
    code: "WELCOME50",
    amount: 5000, // $50.00
    currency_code: "usd",
    metadata: { campaign: "welcome-bonus" },
  },
})

// Create multiple gift cards
const { result } = await createGiftCardsWorkflow(container).run({
  input: [
    { amount: 2500, currency_code: "usd" },
    { amount: 5000, currency_code: "usd" },
    { amount: 10000, currency_code: "usd" },
  ],
})
```

## Workflow Steps

The Loyalty Plugin also exports individual workflow steps that can be used in custom workflows:

### Gift Card Steps

- `createGiftCardsStep` - Creates gift cards
- `updateGiftCardsStep` - Updates gift cards  
- `deleteGiftCardsStep` - Deletes gift cards
- `retrieveGiftCardBalanceStep` - Gets gift card balance

### Store Credit Steps

- `createStoreCreditAccountsStep` - Creates store credit accounts
- `creditAccountStep` - Credits store credit accounts
- `debitAccountStep` - Debits store credit accounts

### Cart Steps

- `validateGiftCardBalancesStep` - Validates gift card balances for cart application

**Example of using individual steps**:
```ts title="Custom workflow with steps"
import { 
  createWorkflow, 
  createStep,
  StepResponse, 
} from "@medusajs/framework/workflows-sdk"
import { 
  createGiftCardsStep,
  retrieveGiftCardBalanceStep, 
} from "@medusajs/loyalty-plugin/workflows"

const customGiftCardWorkflow = createWorkflow(
  "custom-gift-card-workflow",
  (input: { amount: number; currency_code: string }) => {
    // Create gift card
    const { giftCards } = createGiftCardsStep({
      amount: input.amount,
      currency_code: input.currency_code,
    })
    
    // Get the balance (for verification)
    const balance = retrieveGiftCardBalanceStep({
      code: giftCards[0].code,
    })
    
    return new WorkflowResponse({
      giftCard: giftCards[0],
      balance: balance,
    })
  }
)
```

## Error Handling

All workflows include proper error handling and rollback mechanisms. Common error scenarios include:

- **Insufficient Balance**: When trying to redeem/debit more than available
- **Invalid Codes**: When gift card or claim codes don't exist
- **Currency Mismatch**: When currencies don't match between cards/accounts and carts
- **Disabled Accounts**: When trying to use inactive gift cards or store credit accounts

**Example error handling**:
```ts title="Error handling example"
try {
  const { result } = await redeemGiftCardWorkflow(container).run({
    input: {
      code: "INVALID123",
      amount: 5000,
      currency_code: "usd",
    },
  })
} catch (error) {
  if (error.message.includes("Gift card not found")) {
    // Handle invalid gift card code
  } else if (error.message.includes("Insufficient balance")) {
    // Handle insufficient balance
  }
  // Handle other errors
}
```
