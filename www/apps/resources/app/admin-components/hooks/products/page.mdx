# {metadata.title}

<Note>

These hooks are available since Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0).

</Note>

The product hooks fetch and mutate products and their variants in the Medusa backend. To fetch variants across all products, use the [product variant hooks](../product-variants/page.mdx) instead.

```tsx
import {
  productsQueryKeys,
  useCreateProduct,
  useDeleteProduct,
  useDeleteVariantLazy,
  useProduct,
  useProductVariants,
  useProducts,
  useUpdateProduct,
  useUpdateProductVariantsBatch,
  variantsQueryKeys,
} from "@medusajs/dashboard/hooks"
```

These hooks are built on [TanStack Query](https://tanstack.com/query/latest). Use them in your [widgets](!docs!/learn/fundamentals/admin/widgets) and [UI routes](!docs!/learn/fundamentals/admin/ui-routes).

## useProducts

Fetches a paginated list of products.

```tsx
const { products, count, isPending } = useProducts({
  limit: 20,
})
```

## useCreateProduct

Creates a product. On success, the hook invalidates the product lists, along with the inventory item and product option lists, since creating a product can create those resources too.

```tsx
const { mutateAsync, isPending } = useCreateProduct()

const handleCreate = async () => {
  const { product } = await mutateAsync({
    title: "Shirt",
    options: [
      { title: "Size", values: ["S", "M"] },
    ],
  })
}
```

### Parameters

<TypeList
  types={[
    {
      name: "options",

    },
  ]}
/>

### Returns

      description: "The promise-based version of `mutate`. It resolves to an object with a `product` property.",

## useUpdateProductVariantsBatch


## useDeleteVariantLazy

Deletes a variant of a product. The hook is bound to the product only, so you pass the variant's ID when you call the mutation. That makes it useful when one component deletes any of a product's variants.

```tsx
const handleDelete = async (variantId: string) => {
```

## productsQueryKeys

A TanStack Query key factory for product queries. Use it to invalidate cached product data after you change a product.

It provides `all`, `lists()`, `list(query)`, `details()`, and `detail(id, query)`.

```tsx
import { useQueryClient } from "@tanstack/react-query"
import {
  productsQueryKeys,
} from "@medusajs/dashboard/hooks"

const Widget = () => {
  const queryClient = useQueryClient()

  const refreshProduct = (id: string) => {
    queryClient.invalidateQueries({
      queryKey: productsQueryKeys.detail(id),
    })
  }

  // ...
}
```

## variantsQueryKeys

A TanStack Query key factory for the variants of a product, which is the factory that `useProductVariants` uses. It's separate from `productVariantQueryKeys`, which the [product variant hooks](../product-variants/page.mdx) use.

```tsx
import { useQueryClient } from "@tanstack/react-query"
import {
  variantsQueryKeys,
} from "@medusajs/dashboard/hooks"

const Widget = () => {
  const queryClient = useQueryClient()

  const refreshVariants = () => {
    queryClient.invalidateQueries({
      queryKey: variantsQueryKeys.lists(),
    })
  }

  // ...
}
```
