</Note>

The price preference hooks retrieve price preferences from the Medusa backend. A price preference controls how prices are displayed and entered for a region or a currency, such as whether prices are tax inclusive.

```tsx
import {
  pricePreferencesQueryKeys,
  usePricePreferences,
} from "@medusajs/dashboard/hooks"
```

These hooks are built on [TanStack Query](https://tanstack.com/query/latest). Use them in your [widgets](!docs!/learn/fundamentals/admin/widgets) and [UI routes](!docs!/learn/fundamentals/admin/ui-routes).

---

## usePricePreferences

Retrieve a paginated list of price preferences. Pass query parameters to filter the price preferences, for example by attribute or value.

```tsx
const { price_preferences, count } = usePricePreferences({
  limit: 20,
})
```

## pricePreferencesQueryKeys

`pricePreferencesQueryKeys` is the query key factory for price preference queries. Use `all`, `lists()`, `list(query)`, `details()`, and `detail(id)` to build the keys that the hook above registers.

Use it to invalidate cached price preference data after a custom mutation:

```tsx
import { useQueryClient } from "@tanstack/react-query"
import {
  pricePreferencesQueryKeys,
} from "@medusajs/dashboard/hooks"

const queryClient = useQueryClient()

queryClient.invalidateQueries({
  queryKey: pricePreferencesQueryKeys.lists(),
})
```
