# {metadata.title}

<Note>

These hooks are available since Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0).

</Note>

The store hooks retrieve the active store from the Medusa backend, including its supported currencies and default sales channel.

```tsx
import {
  storeQueryKeys,
  useStore,
} from "@medusajs/dashboard/hooks"
```

These hooks are built on [TanStack Query](https://tanstack.com/query/latest). Use them in your [widgets](!docs!/learn/fundamentals/admin/widgets) and [UI routes](!docs!/learn/fundamentals/admin/ui-routes).

---

## useStore

Retrieve the active store. The hook lists the stores and returns the first one, so it doesn't accept an ID.

```tsx
const { store, isPending } = useStore({
  fields: "+supported_currencies.*",
})
```

## storeQueryKeys

`storeQueryKeys` is the query key factory for store queries. `useStore` registers its data under `storeQueryKeys.details()`.

Use it to invalidate the cached store after a custom mutation:

```tsx
import { useQueryClient } from "@tanstack/react-query"
import { storeQueryKeys } from "@medusajs/dashboard/hooks"

const queryClient = useQueryClient()

queryClient.invalidateQueries({
  queryKey: storeQueryKeys.details(),
})
```
