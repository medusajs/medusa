# {metadata.title}

<Note>

These hooks are available since Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0).

</Note>

The order hooks fetch an order, its changes, and its preview from the Medusa backend. They also update an order or request an order edit.

```tsx
import {
  ordersQueryKeys,
  useOrder,
  useOrderChanges,
  useOrderPreview,
  useRequestOrderEdit,
  useUpdateOrder,
} from "@medusajs/dashboard/hooks"
```

These hooks are built on [TanStack Query](https://tanstack.com/query/latest). Use them in your [widgets](!docs!/learn/fundamentals/admin/widgets) and [UI routes](!docs!/learn/fundamentals/admin/ui-routes).

---

## useOrder

Fetches a single order by ID.

```tsx
const { order, isPending } = useOrder(orderId, {
  fields: "+items.*",
})
```

## useUpdateOrder

Updates an order. On success, the hook invalidates the order's detail and changes queries.

```tsx
const { mutateAsync, isPending } = useUpdateOrder(orderId)

const handleUpdate = async () => {
  await mutateAsync({
    email: "customer@example.com",
  })
}
```

## useRequestOrderEdit

Requests an order edit, which moves the order edit into a requested state for confirmation. On success, the hook invalidates the order's details, preview, changes, and line items queries.

```tsx
const { mutateAsync } = useRequestOrderEdit(orderId)

const handleRequest = async () => {
  const { order_preview } = await mutateAsync({})
}
```

## ordersQueryKeys

A TanStack Query key factory for order queries. Besides `all`, `lists()`, `list(query)`, `details()`, and `detail(id, query)`, it adds the order-specific keys `preview(id)`, `changes(id)`, `lineItems(id, query)`, and `shippingOptions(id)`.

```tsx
import { useQueryClient } from "@tanstack/react-query"
import { ordersQueryKeys } from "@medusajs/dashboard/hooks"

const Widget = () => {
  const queryClient = useQueryClient()

  const refreshPreview = (id: string) => {
    queryClient.invalidateQueries({
      queryKey: ordersQueryKeys.preview(id),
    })
  }

  // ...
}
```
