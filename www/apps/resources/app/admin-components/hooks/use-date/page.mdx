# {metadata.title}

<Note>

This hook is available since Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0).

</Note>

The `useDate` hook formats dates using the locale of the Medusa Admin's active language. The Medusa Admin uses it to render dates in tables, detail pages, and timelines.

```tsx
import { useDate } from "@medusajs/dashboard/hooks"
```

---

## Example

Use the hook's functions to format a date as an absolute or a relative date:

```tsx
import { useDate } from "@medusajs/dashboard/hooks"
import { Text } from "@medusajs/ui"

const OrderDate = ({ order }) => {
  const { getFullDate, getRelativeDate } = useDate()

  return (
    <div>
      <Text>
        {getFullDate({
          date: order.created_at,
          includeTime: true,
        })}
      </Text>
      <Text>{getRelativeDate(order.created_at)}</Text>
    </div>
  )
}
```

`getFullDate` returns a formatted date, such as `Apr 29, 2025`, and `getRelativeDate` returns a distance from the current time, such as `3 days ago`.
