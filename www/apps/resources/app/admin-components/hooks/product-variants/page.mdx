<Note>

These hooks are available since Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0).

</Note>

The product variant hooks fetch product variants across all products from the Medusa backend. To fetch the variants of a single product, use [useProductVariants](../products/page.mdx#useproductvariants) instead.

```tsx
import {
  productVariantQueryKeys,
  useInfiniteVariants,
  useVariants,
} from "@medusajs/dashboard/hooks"
```

These hooks are built on [TanStack Query](https://tanstack.com/query/latest). Use them in your [widgets](!docs!/learn/fundamentals/admin/widgets) and [UI routes](!docs!/learn/fundamentals/admin/ui-routes).

## useVariants

Fetches a paginated list of product variants.

```tsx
const { variants, count } = useVariants({
  limit: 20,
})
```

## useInfiniteVariants

Fetches product variants page by page, which is useful for infinite scrolling or "load more" lists. The hook manages the `offset` internally and defaults `limit` to `50`.

```tsx
const { data, fetchNextPage, hasNextPage } =
  useInfiniteVariants({ limit: 20 })

const variants = data?.pages.flatMap(
  (page) => page.variants
)
```

## productVariantQueryKeys

A TanStack Query key factory for product variant queries. It provides `all`, `lists()`, `list(query)`, `details()`, and `detail(id, query)`.

`useInfiniteVariants` appends `"__infinite"` to the list key, so its cache entries are separate from the ones of `useVariants`. Invalidating `lists()` invalidates both.

```tsx
import { useQueryClient } from "@tanstack/react-query"
import {
  productVariantQueryKeys,
} from "@medusajs/dashboard/hooks"

const Widget = () => {
  const queryClient = useQueryClient()

  const refreshVariants = () => {
    queryClient.invalidateQueries({
      queryKey: productVariantQueryKeys.lists(),
    })
  }

  // ...
}
```
