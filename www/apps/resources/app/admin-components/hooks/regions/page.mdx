# {metadata.title}

<Note>

These hooks are available since Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0).

</Note>

The region hooks fetch regions from the Medusa backend. Use them to show or select regions in your admin customizations.

```tsx
import {
  regionsQueryKeys,
  useRegion,
  useRegions,
} from "@medusajs/dashboard/hooks"
```

These hooks are built on [TanStack Query](https://tanstack.com/query/latest). Use them in your [widgets](!docs!/learn/fundamentals/admin/widgets) and [UI routes](!docs!/learn/fundamentals/admin/ui-routes).

---

## useRegion

Fetches a single region by ID.

```tsx
const { region, isPending } = useRegion(regionId, {
  fields: "+countries.*",
})
```

## useRegions

Fetches a paginated list of regions.

```tsx
const { regions, count } = useRegions({ limit: 20 })
```

      name: "options",

## regionsQueryKeys

A TanStack Query key factory for region queries. Use it to invalidate cached region data after you change a region.

It provides `all`, `lists()`, `list(query)`, `details()`, and `detail(id, query)`.

```tsx
import { useQueryClient } from "@tanstack/react-query"
import { regionsQueryKeys } from "@medusajs/dashboard/hooks"

const Widget = () => {
  const queryClient = useQueryClient()

  const refreshRegions = () => {
    queryClient.invalidateQueries({
      queryKey: regionsQueryKeys.lists(),
    })
  }

  // ...
}
```
