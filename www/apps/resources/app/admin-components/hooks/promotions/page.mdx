# {metadata.title}

<Note>

These hooks are available since Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0).

</Note>

The promotion hooks fetch promotions from the Medusa backend. Use them to show promotion data in your admin customizations.

```tsx
import {
  promotionsQueryKeys,
  usePromotions,
} from "@medusajs/dashboard/hooks"
```

These hooks are built on [TanStack Query](https://tanstack.com/query/latest). Use them in your [widgets](!docs!/learn/fundamentals/admin/widgets) and [UI routes](!docs!/learn/fundamentals/admin/ui-routes).

---

## usePromotions

Fetches a paginated list of promotions.

```tsx
const { promotions, count, isPending } = usePromotions({
  limit: 20,
})
```

## promotionsQueryKeys

A TanStack Query key factory for promotion queries. Besides `all`, `lists()`, `list(query)`, `details()`, and `detail(id, query)`, it adds the promotion-specific keys `listRules(id, ruleType, query)`, `listRuleAttributes(ruleType, promotionType, applicationMethodTargetType)`, and `listRuleValues(ruleType, ruleValue, query)`.

```tsx
import { useQueryClient } from "@tanstack/react-query"
import {
  promotionsQueryKeys,
} from "@medusajs/dashboard/hooks"

const Widget = () => {
  const queryClient = useQueryClient()

  const refreshPromotions = () => {
    queryClient.invalidateQueries({
      queryKey: promotionsQueryKeys.lists(),
    })
  }

  // ...
}
```
