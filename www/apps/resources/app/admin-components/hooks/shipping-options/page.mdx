<Note>

These hooks are available since Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0).

</Note>

The shipping option hooks retrieve shipping options from the Medusa backend, either a single option by ID or a paginated list.

```tsx
import {
  shippingOptionsQueryKeys,
  useShippingOption,
  useShippingOptions,
} from "@medusajs/dashboard/hooks"
```

These hooks are built on [TanStack Query](https://tanstack.com/query/latest). Use them in your [widgets](!docs!/learn/fundamentals/admin/widgets) and [UI routes](!docs!/learn/fundamentals/admin/ui-routes).

---

## useShippingOption

Retrieve a single shipping option by its ID. Pass a query object as the second parameter to select the fields and relations to retrieve.

```tsx
const { shipping_option, isPending } = useShippingOption(
  "so_123"
)
```

## useShippingOptions

Retrieve a paginated list of shipping options. Pass query parameters to filter the shipping options, for example by stock location or shipping profile.

```tsx
const { shipping_options, count } = useShippingOptions({
  limit: 20,
})
```

## shippingOptionsQueryKeys

`shippingOptionsQueryKeys` is the query key factory for shipping option queries. Use `all`, `lists()`, `list(query)`, `details()`, and `detail(id)` to build the keys that the hooks above register.

Use it to invalidate cached shipping option data after a custom mutation:

```tsx
import { useQueryClient } from "@tanstack/react-query"
import {
  shippingOptionsQueryKeys,
} from "@medusajs/dashboard/hooks"

const queryClient = useQueryClient()

queryClient.invalidateQueries({
  queryKey: shippingOptionsQueryKeys.all,
})
```
