# {metadata.title}

<Note>

This hook is available since Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0).

</Note>

The `useComboboxData` hook loads paginated and searchable options from the Medusa backend for a [Combobox](../../components/combobox/page.mdx) component. The Medusa Admin uses it in forms where the user selects a record, such as a product's collection or a region's countries.

```tsx
import { useComboboxData } from "@medusajs/dashboard/hooks"
```

---

## Example

Pass the hook's returned properties to the `Combobox` component:

```tsx
import { Combobox } from "@medusajs/dashboard/components"
import { useComboboxData } from "@medusajs/dashboard/hooks"
import { sdk } from "../lib/sdk"

const CollectionSelect = ({ value, onChange }) => {
  const collections = useComboboxData({
    queryKey: ["product_collections"],
    queryFn: (params) =>
      sdk.admin.productCollection.list(params),
    getOptions: (data) =>
      data.collections.map((collection) => ({
        label: collection.title,
        value: collection.id,
      })),
  })

  return (
    <Combobox
      value={value}
      onChange={onChange}
      options={collections.options}
      searchValue={collections.searchValue}
      onSearchValueChange={
        collections.onSearchValueChange
      }
      fetchNextPage={collections.fetchNextPage}
      disabled={collections.disabled}
    />
  )
}
```

The hook debounces the search value before sending the `q` query parameter to the Medusa backend, and it loads the next page of options when `fetchNextPage` is called.

To keep a record that the form already selected in the list, pass its ID to `defaultValue` or `selectedValue`. The hook then fetches that record separately and adds it to the beginning of `options`, even when the current page doesn't include it.

## Returns

Along with the following, the hook returns the rest of TanStack Query's [`useInfiniteQuery`](https://tanstack.com/query/latest/docs/framework/react/reference/useInfiniteQuery) result.

<TypeList
  types={[

    },
    {
      name: "searchValue",
      type: "`string`",
      description: "The current value of the search input before debouncing.",

    {

  ]}
