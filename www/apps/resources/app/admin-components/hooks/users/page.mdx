# {metadata.title}

<Note>

These hooks are available since Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0).

</Note>

The user hooks retrieve admin users from the Medusa backend, such as the user that created an order edit or the user assigned to a task.

```tsx
import { useUser } from "@medusajs/dashboard/hooks"
```

These hooks are built on [TanStack Query](https://tanstack.com/query/latest). Use them in your [widgets](!docs!/learn/fundamentals/admin/widgets) and [UI routes](!docs!/learn/fundamentals/admin/ui-routes).

---

## useUser

Retrieve a single admin user by its ID. Pass a query object as the second parameter to select the fields and relations to retrieve.

```tsx
const { user, isPending } = useUser("user_123")
```

<Note>

This hook retrieves the user with the specified ID, not the currently authenticated user.

</Note>
