# {metadata.title}

<Note>

These hooks are available since Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0).

</Note>

The `@medusajs/dashboard/hooks` subpath exports the React hooks that the Medusa Admin uses to fetch data and build its UI. Use them in your [widgets](!docs!/learn/fundamentals/admin/widgets) and [UI routes](!docs!/learn/fundamentals/admin/ui-routes).

```tsx
import { useProducts } from "@medusajs/dashboard/hooks"
```

<Note title="Tip">

Refer to the [Components reference](../components/page.mdx) for the components that pair with these hooks.

</Note>

---

## API Hooks

Use these hooks to fetch or mutate data from the Medusa backend. They are built on [TanStack Query](https://tanstack.com/query/latest) and follow the same patterns used throughout the Medusa Admin.

Each resource also exports a query key factory, which you use to invalidate the resource's cached queries after a mutation.
