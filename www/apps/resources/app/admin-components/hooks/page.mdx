# {metadata.title}

<Note>

These hooks are available since Medusa [v2.20.2](https://github.com/medusajs/medusa/releases/tag/v2.20.2).

</Note>

The `@medusajs/dashboard/hooks` package exports React hooks that you can use in your [admin extensions](!docs!/learn/fundamentals/admin/widgets). These hooks provide data-fetching utilities for core Medusa resources and general-purpose helpers for building admin UI.

---

## API Hooks

Use these hooks to fetch or mutate data from the Medusa backend. They are built on top of [TanStack Query](https://tanstack.com/query/latest) and follow the same patterns used throughout the Medusa Admin dashboard.

## Utility Hooks

### useComboboxData

Fetches and formats data for use in a combobox (select with search) component.

```tsx
import { useComboboxData } from "@medusajs/dashboard/hooks"
```

### useDate

Returns formatting utilities for dates, consistent with the date format used in the Medusa Admin.

```tsx
import { useDate } from "@medusajs/dashboard/hooks"
```

### useDebouncedSearch

Returns a debounced search string and a setter. Useful when building search inputs that call an API.

```tsx
import { useDebouncedSearch } from "@medusajs/dashboard/hooks"

const MyComponent = () => {
  const { searchValue, rawValue, setSearch } =
    useDebouncedSearch()

  // Pass searchValue to your API call and rawValue to the input.
}
```

### useQueryParams

Reads and writes URL query parameters as React state. Useful for keeping filter and pagination state in the URL.

```tsx
import { useQueryParams } from "@medusajs/dashboard/hooks"
```
