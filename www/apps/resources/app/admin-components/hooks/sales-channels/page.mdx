# {metadata.title}

<Note>

These hooks are available since Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0).

</Note>

The sales channel hooks retrieve sales channels from the Medusa backend and manage the products linked to a sales channel.

```tsx
import {
  salesChannelsQueryKeys,
  useSalesChannel,
  useSalesChannelAddProducts,
  useSalesChannelRemoveProducts,
  useSalesChannels,
} from "@medusajs/dashboard/hooks"
```

These hooks are built on [TanStack Query](https://tanstack.com/query/latest). Use them in your [widgets](!docs!/learn/fundamentals/admin/widgets) and [UI routes](!docs!/learn/fundamentals/admin/ui-routes).

---

## useSalesChannel

Retrieve a single sales channel by its ID. The hook returns the sales channel along with the TanStack Query result properties.

```tsx
const { sales_channel, isPending } = useSalesChannel(
  "sc_123"
)
```

## useSalesChannelAddProducts

Add products to a sales channel. Pass the sales channel's ID to the hook, then pass an array of product IDs to `mutate` or `mutateAsync`.

```tsx
const { mutate } = useSalesChannelAddProducts("sc_123")

const handleAdd = () => {
  mutate(["prod_123"])
}
```

## useSalesChannelRemoveProducts

## salesChannelsQueryKeys

`salesChannelsQueryKeys` is the query key factory for sales channel queries. Use `all`, `lists()`, `list(query)`, `details()`, and `detail(id)` to build the keys that the hooks above register.

Use it to invalidate cached sales channel data after a custom mutation:

```tsx
import { useQueryClient } from "@tanstack/react-query"
import {
  salesChannelsQueryKeys,
} from "@medusajs/dashboard/hooks"

const queryClient = useQueryClient()

queryClient.invalidateQueries({
  queryKey: salesChannelsQueryKeys.detail("sc_123"),
})
```
