# {metadata.title}

<Note>

These hooks are available since Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0).

</Note>

The customer hooks fetch customers and their addresses from the Medusa backend. Use them to show customer data in your admin customizations.

```tsx
import {
  customersQueryKeys,
  useCustomer,
  useCustomerAddress,
  useCustomers,
  useListCustomerAddresses,
} from "@medusajs/dashboard/hooks"
```

These hooks are built on [TanStack Query](https://tanstack.com/query/latest). Use them in your [widgets](!docs!/learn/fundamentals/admin/widgets) and [UI routes](!docs!/learn/fundamentals/admin/ui-routes).

---

## useCustomers

Fetches a paginated list of customers. Pass query parameters to filter, paginate, or select the fields of the returned customers.

```tsx
const { customers, count, isPending } = useCustomers({
  limit: 20,
})
```

## customersQueryKeys

A TanStack Query key factory for customer queries. Use it to invalidate cached customer data after you change a customer.

It provides `all`, `lists()`, `list(query)`, `details()`, and `detail(id, query)`.

```tsx
import { useQueryClient } from "@tanstack/react-query"
import {
  customersQueryKeys,
} from "@medusajs/dashboard/hooks"

const Widget = () => {
  const queryClient = useQueryClient()

  const refreshCustomer = (id: string) => {
    queryClient.invalidateQueries({
      queryKey: customersQueryKeys.detail(id),
    })
  }

  // ...
}
```
