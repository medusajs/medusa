# {metadata.title}

<Note title="Archive" type="warning">

The guides in this section are kept for reference only. As of Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0), the `@medusajs/dashboard` package exports these components, so you no longer have to build them yourself.

</Note>

Before Medusa v2.21.0, you had to copy the Medusa Admin's components into your project to match its design conventions. The guides in this section show how to build those components.

Medusa now exports the same components from the `@medusajs/dashboard` package. Use the exported components instead, as Medusa maintains and updates them along with the Medusa Admin.
