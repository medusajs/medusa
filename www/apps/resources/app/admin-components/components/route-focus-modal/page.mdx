# {metadata.title}

<Note>

This component is available since Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0).

</Note>

The `RouteFocusModal` component renders a full-screen modal that covers the page behind it. The Medusa Admin uses it for forms that need a lot of space, such as the form that creates a region.

```tsx
import { RouteFocusModal } from "@medusajs/dashboard/components"
```

---

## Route Modals

`RouteFocusModal` is tied to a route, not to a trigger button. You render it as the root element of a [UI route](!docs!/learn/fundamentals/admin/ui-routes) that is nested under the page it belongs to. When the user navigates to that route, the modal opens. When the user closes the modal, `RouteFocusModal` navigates back to the previous route.

So, to open the modal, link the user to the modal's route. For example, link to `/brands/create` from the brand list page.

Use `RouteFocusModal` for create forms and multi-step flows, and use the [RouteDrawer](../route-drawer/page.mdx) for smaller edit forms.

---

## Example

Consider a UI route at `src/admin/routes/brands/create/page.tsx` that creates a brand:

```tsx title="src/admin/routes/brands/create/page.tsx"
import { Button, Heading, Input } from "@medusajs/ui"
import {
  RouteFocusModal,
  useRouteModal,
} from "@medusajs/dashboard/components"
import { useForm } from "react-hook-form"

const BrandCreate = () => {
  return (
    <RouteFocusModal>
      <CreateBrandForm />
    </RouteFocusModal>
  )
}

const CreateBrandForm = () => {
  const { handleSuccess } = useRouteModal()
  const form = useForm({
    defaultValues: {
      name: "",
    },
  })

  const handleSubmit = form.handleSubmit(async (data) => {
    const brand = await createBrand(data)
    handleSuccess(`../${brand.id}`)
  })

  return (
    <RouteFocusModal.Form form={form}>
      <form onSubmit={handleSubmit}>
        <RouteFocusModal.Header />
        <RouteFocusModal.Body>
          <Heading>Create Brand</Heading>
          <Input {...form.register("name")} />
        </RouteFocusModal.Body>
        <RouteFocusModal.Footer>
          <RouteFocusModal.Close asChild>
            <Button variant="secondary" size="small">
              Cancel
            </Button>
          </RouteFocusModal.Close>
          <Button type="submit" size="small">
            Create
          </Button>
        </RouteFocusModal.Footer>
      </form>
    </RouteFocusModal.Form>
  )
}

export default BrandCreate
```

Call the `useRouteModal` hook in a child of the `RouteFocusModal`, since the modal provides its context. The hook returns `handleSuccess`, which closes the modal after a successful submission. Refer to the [Route Drawer](../route-drawer/page.mdx#useroutemodal) documentation for the hook's returned values, including `setCloseOnEscape` that controls whether the <Kbd>Escape</Kbd> key closes the modal.

## Stacking Modals

To open another modal above a `RouteFocusModal`, such as a table for the user to select items from, use the [StackedFocusModal](../stacked-focus-modal/page.mdx) or the [StackedDrawer](../stacked-drawer/page.mdx) components. Both are controlled with the `useStackedModal` hook.
