# {metadata.title}

<Note>

This component is available since Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0).

</Note>

The `Thumbnail` component shows a small image in a bordered box, falling back to a photo icon when there's no image. The Medusa Admin uses it next to product names in tables and lists.

```tsx
import { Thumbnail } from "@medusajs/dashboard/components"
```

---

## Example

Use `Thumbnail` in a [widget](!docs!/learn/fundamentals/admin/widgets) or [UI route](!docs!/learn/fundamentals/admin/ui-routes) to show a record's image:

```tsx
import { Thumbnail } from "@medusajs/dashboard/components"
import { Text } from "@medusajs/ui"

const ProductItem = ({ product }) => {
  return (
    <div className="flex items-center gap-x-3">
      <Thumbnail
        src={product.thumbnail}
        alt={product.title}
        size="small"
      />
      <Text size="small">{product.title}</Text>
    </div>
  )
}
```

## Props

The component accepts the `ThumbnailProps` type:

<TypeList
  types={[
    {
      name: "src",

    {
      name: "alt",

    },
    {
      name: "size",

      defaultValue: "base",
      description: `The thumbnail's size.`,
    },
  ]}
