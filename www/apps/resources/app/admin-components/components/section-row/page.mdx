# {metadata.title}

<Note>

This component is available since Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0).

</Note>

The `SectionRow` component shows a title and its value side by side in a row. The Medusa Admin uses it in the detail sections of its pages, such as a product's general section.

```tsx
import { SectionRow } from "@medusajs/dashboard/components"
```

---

## Example

Use `SectionRow` inside a container in a [widget](!docs!/learn/fundamentals/admin/widgets) or [UI route](!docs!/learn/fundamentals/admin/ui-routes):

```tsx
import { SectionRow } from "@medusajs/dashboard/components"
import { Container, Heading } from "@medusajs/ui"

const BrandGeneralSection = ({ brand }) => {
  return (
    <Container className="divide-y p-0">
      <div className="px-6 py-4">
        <Heading level="h2">Brand</Heading>
      </div>
      <SectionRow title="Name" value={brand.name} />
      <SectionRow title="Handle" value={brand.handle} />
    </Container>
  )
}
```

Medusa shows a dash when you pass an empty `value`.

  ]}
