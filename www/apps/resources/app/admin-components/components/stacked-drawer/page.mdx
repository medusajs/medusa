# {metadata.title}

<Note>

This component is available since Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0).

</Note>

The `StackedDrawer` component renders a drawer above a route modal. The Medusa Admin uses it to let the user pick resources without leaving the form, such as choosing customer groups while configuring a price list.

```tsx
import { StackedDrawer } from "@medusajs/dashboard/components"
```

---

## Stacked Modals

Render a `StackedDrawer` inside a [RouteDrawer](../route-drawer/page.mdx) or a [RouteFocusModal](../route-focus-modal/page.mdx), which both provide the stacked modal context. Unlike route modals, a `StackedDrawer` is not tied to a route. The user opens it with a trigger, and the parent modal stays mounted underneath.

Every `StackedDrawer` requires an `id` prop. The parent modal uses the ID to track which stacked modal is open, so you can render more than one stacked modal in the same form.

---

## Example

The following UI route renders a `StackedDrawer` inside a `RouteFocusModal` to select a brand:

```tsx title="src/admin/routes/products/[id]/brand/page.tsx"
import { Button, Heading } from "@medusajs/ui"
import {
  RouteFocusModal,
  StackedDrawer,
} from "@medusajs/dashboard/components"

const STACKED_MODAL_ID = "select-brand"

const ProductBrand = () => {
  return (
    <RouteFocusModal>
      <RouteFocusModal.Header />
      <RouteFocusModal.Body>
        <StackedDrawer id={STACKED_MODAL_ID}>
          <StackedDrawer.Trigger asChild>
            <Button variant="secondary" size="small">
              Select Brand
            </Button>
          </StackedDrawer.Trigger>
          <StackedDrawer.Content>
            <StackedDrawer.Header>
              <StackedDrawer.Title asChild>
                <Heading>Select Brand</Heading>
              </StackedDrawer.Title>
            </StackedDrawer.Header>
            <StackedDrawer.Body>
              <BrandList />
            </StackedDrawer.Body>
            <StackedDrawer.Footer>
              <StackedDrawer.Close asChild>
                <Button variant="secondary" size="small">
                  Cancel
                </Button>
              </StackedDrawer.Close>
            </StackedDrawer.Footer>
          </StackedDrawer.Content>
        </StackedDrawer>
      </RouteFocusModal.Body>
    </RouteFocusModal>
  )
}

export default ProductBrand
```

## useStackedModal

Use the `useStackedModal` hook to control a stacked modal programmatically. For example, close the drawer after the user confirms their selection.

```tsx
import { useStackedModal } from "@medusajs/dashboard/components"
```

Call the hook in a component rendered inside a route modal. It throws an error if you use it elsewhere.

### Returned Values

### Example

```tsx title="src/admin/routes/products/[id]/brand/page.tsx"
import { Button } from "@medusajs/ui"
import { useStackedModal } from "@medusajs/dashboard/components"

const BrandList = () => {
  const { setIsOpen } = useStackedModal()

  const handleSave = () => {
    setIsOpen("select-brand", false)
  }

  return (
    <Button size="small" onClick={handleSave}>
      Save
    </Button>
  )
}
```
