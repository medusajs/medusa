<Note>

This component is available since Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0).

</Note>

The `StackedFocusModal` component renders a full-screen modal above a route modal. The Medusa Admin uses it for selections that need a lot of space, such as the table that adds countries to a region.

```tsx
import {
  StackedFocusModal,
} from "@medusajs/dashboard/components"
```

---

## Stacked Modals

Render a `StackedFocusModal` inside a [RouteFocusModal](../route-focus-modal/page.mdx) or a [RouteDrawer](../route-drawer/page.mdx), which both provide the stacked modal context. Unlike route modals, a `StackedFocusModal` is not tied to a route. The user opens it with a trigger, and the parent modal stays mounted underneath.

Every `StackedFocusModal` requires an `id` prop. The parent modal uses the ID to track which stacked modal is open, so you can render more than one stacked modal in the same form.

Use a `StackedFocusModal` when the content needs the full screen, such as a data table. For narrower content, use the [StackedDrawer](../stacked-drawer/page.mdx).

---

## Example

The following UI route renders a `StackedFocusModal` inside a `RouteFocusModal` to select products:

```tsx title="src/admin/routes/brands/[id]/products/page.tsx"
import { Button, Heading } from "@medusajs/ui"
import {
  RouteFocusModal,
  StackedFocusModal,
} from "@medusajs/dashboard/components"

const STACKED_MODAL_ID = "select-products"

const BrandProducts = () => {
  return (
    <RouteFocusModal>
      <RouteFocusModal.Header />
      <RouteFocusModal.Body>
        <StackedFocusModal id={STACKED_MODAL_ID}>
          <StackedFocusModal.Trigger asChild>
            <Button variant="secondary" size="small">
              Add Products
            </Button>
          </StackedFocusModal.Trigger>
          <StackedFocusModal.Content>
            <StackedFocusModal.Header>
              <StackedFocusModal.Title asChild>
                <Heading>Add Products</Heading>
              </StackedFocusModal.Title>
            </StackedFocusModal.Header>
            <StackedFocusModal.Body>
              <ProductTable />
            </StackedFocusModal.Body>
            <StackedFocusModal.Footer>
              <StackedFocusModal.Close asChild>
                <Button variant="secondary" size="small">
                  Cancel
                </Button>
              </StackedFocusModal.Close>
            </StackedFocusModal.Footer>
          </StackedFocusModal.Content>
        </StackedFocusModal>
      </RouteFocusModal.Body>
    </RouteFocusModal>
  )
}

export default BrandProducts
```

To close the modal from your own code, such as after the user confirms the selection, use the `useStackedModal` hook. Refer to the [Stacked Drawer](../stacked-drawer/page.mdx#usestackedmodal) documentation for the hook's returned values.

## useStackedModal

`StackedFocusModal` shares the `useStackedModal` hook with the [StackedDrawer](../stacked-drawer/page.mdx#usestackedmodal). The hook returns `getIsOpen` and `setIsOpen` to read and change a stacked modal's open state by its ID, and `register` and `unregister` that the components call for you.

```tsx title="src/admin/routes/brands/[id]/products/page.tsx"
import { Button } from "@medusajs/ui"
import { useStackedModal } from "@medusajs/dashboard/components"

const ProductTable = () => {
  const { setIsOpen } = useStackedModal()

  const handleSave = () => {
    setIsOpen("select-products", false)
  }

  return (
    <Button size="small" onClick={handleSave}>
      Save
    </Button>
  )
}
```
