# {metadata.title}

<Note>

This component is available since Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0).

</Note>

The `RouteDrawer` component renders a drawer that slides in from the side of the screen. The Medusa Admin uses it for edit forms, such as the form that edits a customer's details.

```tsx
import { RouteDrawer } from "@medusajs/dashboard/components"
```

---

## Route Modals

`RouteDrawer` is tied to a route, not to a trigger button. You render it as the root element of a [UI route](!docs!/learn/fundamentals/admin/ui-routes) that is nested under the page it edits. When the user navigates to that route, the drawer opens. When the user closes the drawer, `RouteDrawer` navigates back to the previous route.

So, to open the drawer, link the user to the drawer's route. For example, link to `/brands/:id/edit` from the brand's details page.

---

## Example

Consider a UI route at `src/admin/routes/brands/[id]/edit/page.tsx` that edits a brand:

```tsx title="src/admin/routes/brands/[id]/edit/page.tsx"
import { Heading } from "@medusajs/ui"
import { RouteDrawer } from "@medusajs/dashboard/components"
import { useParams } from "react-router-dom"

const BrandEdit = () => {
  const { id } = useParams()

  return (
    <RouteDrawer>
      <RouteDrawer.Header>
        <RouteDrawer.Title asChild>
          <Heading>Edit Brand</Heading>
        </RouteDrawer.Title>
      </RouteDrawer.Header>
      <EditBrandForm id={id!} />
    </RouteDrawer>
  )
}

export default BrandEdit
```

`EditBrandForm` renders the form's fields, as explained in the [useRouteModal](#useroutemodal) section.

## useRouteModal

Use the `useRouteModal` hook in components rendered inside a `RouteDrawer` or a [RouteFocusModal](../route-focus-modal/page.mdx). It gives you access to the modal's route context.

```tsx
import { useRouteModal } from "@medusajs/dashboard/components"
```

The hook throws an error if you use it outside of a route modal.

### Returned Values

### Example

The form component uses `handleSuccess` to close the drawer after the brand is updated:

```tsx title="src/admin/routes/brands/[id]/edit/page.tsx"
import { Button, Input, toast } from "@medusajs/ui"
import {
  RouteDrawer,
  useRouteModal,
} from "@medusajs/dashboard/components"
import { useForm } from "react-hook-form"

const EditBrandForm = ({ id }: { id: string }) => {
  const { handleSuccess } = useRouteModal()
  const form = useForm({
    defaultValues: {
      name: "",
    },
  })

  const handleSubmit = form.handleSubmit(async (data) => {
    await updateBrand(id, data)
    toast.success("Brand updated")
    handleSuccess()
  })

  return (
    <RouteDrawer.Form form={form}>
      <form onSubmit={handleSubmit}>
        <RouteDrawer.Body>
          <Input {...form.register("name")} />
        </RouteDrawer.Body>
        <RouteDrawer.Footer>
          <RouteDrawer.Close asChild>
            <Button variant="secondary" size="small">
              Cancel
            </Button>
          </RouteDrawer.Close>
          <Button type="submit" size="small">
            Save
          </Button>
        </RouteDrawer.Footer>
      </form>
    </RouteDrawer.Form>
  )
}
```
