# {metadata.title}

<Note>

This component is available since Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0).

</Note>

The `ConditionalTooltip` component wraps its children in a [Tooltip](!ui!/components/tooltip) only when a condition is met, and renders them unchanged otherwise. The Medusa Admin uses it for elements whose tooltip is only useful in some states, such as truncated table cells and disabled action menu items.

```tsx
import {
  ConditionalTooltip,
} from "@medusajs/dashboard/components"
```

---

## Example

Show a tooltip on a product's title only when the title is too long to fit:

```tsx
import { defineWidgetConfig } from "@medusajs/admin-sdk"
import {
  ConditionalTooltip,
} from "@medusajs/dashboard/components"
import { Container, Text } from "@medusajs/ui"

const ProductTitleWidget = () => {
  const title = "A very long product title"

  return (
    <Container>
      <ConditionalTooltip
        content={title}
        showTooltip={title.length > 20}
      >
        <Text className="truncate">{title}</Text>
      </ConditionalTooltip>
    </Container>
  )
}

export const config = defineWidgetConfig({
  zone: "product.details.before",
})

export default ProductTitleWidget
```

## Props

The component accepts all props of the [Tooltip](!ui!/components/tooltip) component from Medusa UI, in addition to the following prop:

<TypeList
  types={[
    {
      name: "showTooltip",
      type: "`boolean`",
      optional: true,
      defaultValue: "false",
      description:
        "Whether to wrap the children in a tooltip. When `false`, the children render without a tooltip.",
    },
    {
      name: "children",
      type: "`React.ReactNode`",
      optional: false,
      description: "The element that the tooltip is shown for.",
    },
    {
      name: "content",
      type: "`React.ReactNode`",
      optional: false,
      description: `The tooltip's content. This prop is passed to the underlying [Tooltip](!ui!/components/tooltip) component.`,
    },
  ]}
/>
