# {metadata.title}

<Note>

These components are available since Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0).

</Note>

The `@medusajs/dashboard/components` subpath exports the React components that the Medusa Admin uses to build its pages. Use them in your [widgets](!docs!/learn/fundamentals/admin/widgets) and [UI routes](!docs!/learn/fundamentals/admin/ui-routes) to match the Medusa Admin's design conventions without re-implementing the components.

```tsx
import {
  ActionMenu,
  SectionRow,
} from "@medusajs/dashboard/components"
```

<Note title="Tip">

These components build on the [Medusa UI package](!ui!). Refer to the [Medusa UI documentation](!ui!) for the underlying primitives, such as buttons and inputs.

</Note>
