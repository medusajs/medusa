# {metadata.title}

<Note>

These utilities are available since Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0).

</Note>

The `@medusajs/dashboard/lib` subpath exports the utilities that back the Medusa Admin's configurable tables. Use them to define which data a [ConfigurableDataTable](../../components/configurable-data-table/page.mdx) shows, and how it renders each cell.

```tsx
import {
  createTableAdapter,
  defineCellRenderer,
} from "@medusajs/dashboard/lib"
```

<Note title="Tip">

Refer to the [View Configurations guide](../../../commerce-modules/settings/configure-view-configurations/page.mdx) for full examples of both utilities.

</Note>

## createTableAdapter

Creates a type-safe table adapter that tells a `ConfigurableDataTable` which entity to render, how to fetch its data, and how each row behaves. The utility applies defaults for `getRowId`, `pageSize`, and `queryPrefix`, then merges your adapter on top of them.

```tsx
import { createTableAdapter } from "@medusajs/dashboard/lib"
import { sdk } from "../lib/sdk"
import { useQuery } from "@tanstack/react-query"

export const brandTableAdapter = createTableAdapter({
  entity: "brand",
  entityName: "Brands",
  useData: (fields, params) => {
    const { data, isLoading, isError, error } = useQuery({
      queryKey: ["brands", fields, params],
      queryFn: () => sdk.client.fetch("/admin/brands", {
        query: { ...params, fields },
      }),
    })

    return {
      data: data?.brands,
      count: data?.count,
      isLoading,
      isError,
      error,
    }
  },
  getRowHref: (brand) => `/brands/${brand.id}`,
})
```

## defineCellRenderer

Registers a cell renderer for a render mode in the global registry. A column opts into the renderer through its render mode. Registering an existing render mode replaces it, which lets you override a built-in renderer.

Call it once when your [admin extension](!docs!/learn/fundamentals/admin) loads.

```tsx
import { defineCellRenderer } from "@medusajs/dashboard/lib"
import { Badge } from "@medusajs/ui"

defineCellRenderer("brand_tier", {
  render: (value, row, column, t) => (
    <Badge size="xsmall">{value ?? "-"}</Badge>
  ),
  align: "center",
  truncateTooltip: false,
})
```
