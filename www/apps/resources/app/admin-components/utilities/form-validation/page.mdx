# {metadata.title}

<Note>

These utilities are available since Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0).

</Note>

The `@medusajs/dashboard/lib` subpath exports the [Zod](https://zod.dev/) schemas and validation helpers that the Medusa Admin uses in its forms. Use them with [react-hook-form](https://react-hook-form.com/) and the `Form` component, as shown in the [Forms guide](../../guides/forms/page.mdx), to validate your [admin extension](!docs!/learn/fundamentals/admin) forms the same way the Medusa Admin does.

```tsx
import {
  AddressSchema,
  EmailSchema,
  metadataFormSchema,
  optionalFloat,
  optionalInt,
  partialFormValidation,
} from "@medusajs/dashboard/lib"
```

## optionalInt and optionalFloat

Zod schemas for optional number inputs that accept either a string or a number, since an input's value is a string. Both treat an empty string and `undefined` as valid, and both reject negative values. `optionalInt` also rejects values that aren't whole numbers.

Both schemas use the Medusa Admin's translated error messages.

```tsx
import { z } from "zod"
import {
  optionalFloat,
  optionalInt,
} from "@medusajs/dashboard/lib"

const schema = z.object({
  quantity: optionalInt,
  weight: optionalFloat,
})
```

## metadataFormSchema

A Zod schema for the key-value metadata form that the Medusa Admin uses to edit a resource's `metadata` property. It validates an array of rows, where each row holds a key, a value, and flags that track how the row changed.

```tsx
import { z } from "zod"
import { metadataFormSchema } from "@medusajs/dashboard/lib"

const schema = z.object({
  metadata: metadataFormSchema,
})
```

## partialFormValidation

Validates a subset of a form's fields against a Zod schema. Use it in a multi-step form to validate only the fields of the current step before moving to the next one.

The function clears the errors of the passed fields, validates their current values, and sets an error on each field that fails.

```tsx
import { z } from "zod"
import {
  partialFormValidation,
} from "@medusajs/dashboard/lib"

const schema = z.object({
  name: z.string().min(1),
  email: z.string().email(),
})

const onContinue = () => {
  const isValid = partialFormValidation(
    form,
    ["name", "email"],
    schema
  )

  if (isValid) {
    setStep("details")
  }
}
```

### Parameters

<TypeList
  types={[
    {

      description: "The form returned by react-hook-form's `useForm` hook.",
    },
    {

    },
    {

    },

/>

### Returns

Returns a `boolean` that is `true` when every passed field is valid. When it returns `false`, it has already set the errors on the form.

## AddressSchema and EmailSchema

Zod schemas for the address and email fields that the Medusa Admin uses in its forms.

```tsx
import { z } from "zod"
import {
  AddressSchema,
  EmailSchema,
} from "@medusajs/dashboard/lib"

const schema = z.object({
  shipping_address: AddressSchema,
}).merge(EmailSchema)
```
