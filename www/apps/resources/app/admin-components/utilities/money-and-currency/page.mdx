# {metadata.title}

<Note>

These utilities are available since Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0).

</Note>

The `@medusajs/dashboard/lib` subpath exports the utilities that the Medusa Admin uses to format amounts and look up currency data. Use them in your [admin extensions](!docs!/learn/fundamentals/admin) to display prices and totals the same way the Medusa Admin does.

```tsx
import {
  castNumber,
  currencies,
  formatCurrency,
  getCurrencyDecimalDigits,
  getCurrencySymbol,
  getDecimalDigits,
  getLocaleAmount,
  getNativeSymbol,
  getStylizedAmount,
} from "@medusajs/dashboard/lib"
```

---

## getStylizedAmount

Formats an amount in the Medusa Admin's style, placing the currency's native symbol before the amount and the uppercase currency code after it. The Medusa Admin uses it for totals.

```tsx
import { getStylizedAmount } from "@medusajs/dashboard/lib"

getStylizedAmount(10, "usd") // "$ 10.00 USD"
```

### Parameters

<TypeList
  types={[
    {
      name: "amount",
      type: "`number`",
      optional: false,
      description: "The amount to format.",
    },
    {
      name: "currencyCode",
      type: "`string`",
      optional: false,
      description: "The currency code, such as `usd`. The casing doesn't matter.",
    },
  ]}
/>

### Returns

Returns a `string` of the formatted amount. When the amount is smaller than the currency's rounding precision, the formatted amount shows an explicit sign.

## getLocaleAmount

Formats an amount as a currency string using the browser's locale and the currency's narrow symbol.

```tsx
import { getLocaleAmount } from "@medusajs/dashboard/lib"

getLocaleAmount(10, "usd") // "$10.00" in the en-US locale
```

Returns the native symbol of a currency by formatting a zero amount and stripping the digits and separators.

```tsx

getNativeSymbol("usd") // "$"
```

## getDecimalDigits

Returns the number of decimal digits of a currency from the `currencies` object. Returns `0` when the currency isn't in the object.

```tsx
import { getDecimalDigits } from "@medusajs/dashboard/lib"

getDecimalDigits("usd") // 2
```

### Parameters

<TypeList
  types={[
    {
      name: "currency",
      type: "`string`",
      optional: false,
      description: "The currency code. The casing doesn't matter.",
    },
  ]}
/>

### Returns

Returns a `number` of the currency's decimal digits, or `0` if the currency isn't supported.

## castNumber

Converts a value entered in an input into a number, replacing a comma decimal separator with a period. Use it with a Zod schema that accepts both a string and a number.

```tsx
import { castNumber } from "@medusajs/dashboard/lib"

castNumber("10,5") // 10.5
castNumber(10.5) // 10.5
```

### Parameters

<TypeList
  types={[
    {
      name: "number",
      type: "`number | string`",
      optional: false,
      description: "The value to convert into a number.",
    },
  ]}
/>

### Returns

Returns a `number`.

## currencies

An object of the currencies that the Medusa Admin supports, keyed by uppercase currency code. Each value is a `CurrencyInfo` object.

```tsx
import { currencies } from "@medusajs/dashboard/lib"

currencies.USD.name // "US Dollar"
```

## getCurrencySymbol and getCurrencyDecimalDigits

Read a currency's native symbol or number of decimal digits from the `currencies` object.

<Note type="warning">

Both functions throw an error when the currency code isn't in the `currencies` object. Use `getDecimalDigits` instead if you need a `0` fallback.

</Note>

```tsx
import {
  getCurrencyDecimalDigits,
  getCurrencySymbol,
} from "@medusajs/dashboard/lib"

getCurrencySymbol("usd") // "$"
getCurrencyDecimalDigits("usd") // 2
```
