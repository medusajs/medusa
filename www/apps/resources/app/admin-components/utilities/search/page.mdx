# {metadata.title}

<Note>

These utilities are available since Medusa [v2.21.0](https://github.com/medusajs/medusa/releases/tag/v2.21.0).

</Note>

The `@medusajs/dashboard/lib` subpath exports the utilities that manage the registry of entities in the Medusa Admin's global search. Use them to add your custom entities to the search palette, or to override the entities that Medusa registers by default.

```tsx
import {
  clearSearchEntities,
  defineSearchEntity,
  getSearchEntity,
  getSearchEntityNames,
  hasSearchEntity,
} from "@medusajs/dashboard/lib"
```

Apps and plugins register their entities from the file `src/admin/search-entities.tsx`. The Medusa Admin seeds the registry with its built-in commerce entities before it runs your registrations, so you can override a built-in entity by registering it again under the same name.

---

## defineSearchEntity

Registers or replaces a searchable entity in the Medusa Admin's global search. The entity's definition sets the group heading in the search palette, an optional keyboard shortcut, and how to turn a search result into a palette item.

```tsx title="src/admin/search-entities.tsx"
import { defineSearchEntity } from "@medusajs/dashboard/lib"

defineSearchEntity("organization", {
  groupLabel: "Organizations",
  shortcut: {
    keys: { Mac: ["G", "Z"] },
    label: "Go to Organizations",
    to: "/organizations",
  },
  transform: (org) => ({
    id: org.id,
    title: org.name,
    subtitle: org.billing_email,
    to: `/organizations/${org.id}`,
    value: `organization:${org.id}`,
  }),
})
```

## clearSearchEntities

Removes every registered search entity, including the commerce entities that Medusa registers by default. Call it before registering your own set when the default entities shouldn't appear in the Medusa Admin's search.

```tsx title="src/admin/search-entities.tsx"
import {
  clearSearchEntities,
  defineSearchEntity,
} from "@medusajs/dashboard/lib"

clearSearchEntities()

defineSearchEntity("brand", {
  groupLabel: "Brands",
  transform: (brand) => ({
    id: brand.id,
    title: brand.name,
    to: `/brands/${brand.id}`,
    value: `brand:${brand.id}`,
  }),
})
```

## getSearchEntity

Returns a registered entity's definition by its name.

```tsx
import { getSearchEntity } from "@medusajs/dashboard/lib"

const definition = getSearchEntity("brand")
```

### Parameters

<TypeList
  types={[
    {
      name: "name",
      type: "`string`",
      optional: false,
      description: "The entity's name.",
    },
  ]}
/>

### Returns

Returns the `SearchEntityDefinition`, or `undefined` when no entity is registered under that name.

---

## getSearchEntityNames

Returns the names of the entities that can be searched, in registration order. Entities that only contribute a shortcut are left out, since there's nothing to query for them.

```tsx
import {
  getSearchEntityNames,
} from "@medusajs/dashboard/lib"

const names = getSearchEntityNames()
```

### Returns

Returns a `string[]` of the searchable entities' names.

---

## hasSearchEntity

Returns whether a name is registered as a searchable entity. It returns `false` for entries that only contribute a shortcut.

```tsx
import { hasSearchEntity } from "@medusajs/dashboard/lib"

if (hasSearchEntity("brand")) {
  // ...
}
```

### Parameters

<TypeList
  types={[
    {
      name: "name",
      type: "`string`",
      optional: false,
      description: "The entity's name.",
    },
  ]}
/>

### Returns

Returns a `boolean` that is `true` when the entity is registered and has a `transform` function.
