## User Module

You assign roles to admin users to control their access. Medusa stores each of these grants as an `RbacRoleAssignment` record, as explained in the [RBAC Concepts](../concepts/page.mdx#role-assignment) guide.

Since the assignment stores the granted entity's type and ID, it isn't a stored link between two data models. Instead, Medusa defines read-only links that expose the roles of a `User` or an `Invite` from the [User Module](../../commerce-modules/user/page.mdx).

An admin user can have multiple roles, and a role can be assigned to multiple users. The user's effective policies are the union of the policies from all their assigned roles.

### Retrieve with Query

To retrieve the roles of an admin user with [Query](!docs!/learn/fundamentals/module-links/query), pass `rbac_roles.*` in `fields`:

<CodeTabs group="relation-query">
  <CodeTab label="query.graph" value="method">

```ts
const { data: users } = await query.graph({
  entity: "user",
  fields: [
    "rbac_roles.*",
  ],
})

// users[0].rbac_roles
```

  </CodeTab>
  <CodeTab label="useQueryGraphStep" value="step">

```ts
import { useQueryGraphStep } from "@medusajs/medusa/core-flows"

// ...

const { data: users } = useQueryGraphStep({
  entity: "user",
  fields: [
    "rbac_roles.*",
  ],
})

// users[0].rbac_roles
```

  </CodeTab>
</CodeTabs>

Pass the same field when querying the `invite` entity to retrieve the roles that an invite grants once the user accepts it.

To find the entities that a role is assigned to, query the `rbac_role_assignment` entity instead:

```ts
const { data: assignments } = await query.graph({
  entity: "rbac_role_assignment",
  fields: ["reference", "reference_id"],
  filters: {
    role_id: "role_123",
    reference: "user",
  },
})
```

### Manage Role Assignments

To assign a role to an admin user, use the `assignRolesWorkflow`:

export const assignHighlights = [
  ["10", "reference", "Assign the role to a user."],
  ["14", "granting_actor_id", "The user performing the assignment."],
]

```ts highlights={assignHighlights}
import {
  assignRolesWorkflow,
} from "@medusajs/medusa/core-flows"

await assignRolesWorkflow(container).run({
  input: {
    assignments: [
      {
        role_id: "role_123",
        reference: "user",
        reference_id: "user_123",
      },
    ],
    granting_actor_id: "user_456",
  },
})
```

To remove a role from an admin user, use the `unassignRolesWorkflow` with the same input shape:

```ts
import {
  unassignRolesWorkflow,
} from "@medusajs/medusa/core-flows"

await unassignRolesWorkflow(container).run({
  input: {
    assignments: [
      {
        role_id: "role_123",
        reference: "user",
        reference_id: "user_123",
      },
    ],
    granting_actor_id: "user_456",
  },
})
```

Both workflows check that the actor in `granting_actor_id` already has all the policies of the roles being changed.
