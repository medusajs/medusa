# {metadata.title}

<Note title="Removed">

Since [Medusa v2.22.0](https://github.com/medusajs/medusa/releases/tag/v2.22.0), the [Workflow Engine Module](../page.mdx) replaces the Redis Workflow Engine Module.

</Note>

The Redis Workflow Engine Module stored workflow executions in Redis, and you used it in production. The Workflow Engine Module now stores executions in your application's database, so it doesn't need Redis.

To keep using Redis for faster communication between your instances, set the Workflow Engine Module's `notifier` option:

```ts title="medusa-config.ts"
module.exports = defineConfig({
  // ...
  modules: [
    {
      resolve: "@medusajs/medusa/workflows",
      options: {
        notifier: {
          type: "redis",
          url: process.env.REDIS_URL,
        },
      },
    },
  ],
})
```

If your `medusa-config.ts` registers `@medusajs/medusa/workflow-engine-redis`, Medusa replaces it with the Workflow Engine Module and uses its Redis URL for the notifier.

Learn how to upgrade in the [Upgrade from the In-Memory or Redis Module](../page.mdx#upgrade-from-the-in-memory-or-redis-module) section.
