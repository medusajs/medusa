# {metadata.title}

<Note title="Removed">

Since [Medusa v2.22.0](https://github.com/medusajs/medusa/releases/tag/v2.22.0), the [Workflow Engine Module](../page.mdx) replaces the In-Memory Workflow Engine Module.

</Note>

The In-Memory Workflow Engine Module stored workflow executions in memory, and you used it in development. The Workflow Engine Module now runs workflows both in development and in production, and stores their executions in your application's database.

If your `medusa-config.ts` registers `@medusajs/medusa/workflow-engine-inmemory`, you can remove it. Medusa replaces it with the Workflow Engine Module.

Learn how to upgrade in the [Upgrade from the In-Memory or Redis Module](../page.mdx#upgrade-from-the-in-memory-or-redis-module) section.
