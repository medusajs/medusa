# {metadata.title}

This recipe provides the general steps to create an ecommerce store with Medusa.

## Overview

Businesses use ecommerce stores to:

- Provide an online catalog for customers.
- Accept customer orders and payment.
- Manage their store's data and logistics.

Medusa provides all essential commerce features out-of-the-box. Businesses can go live and start selling without making any adjustments.

Businesses can also power-up their store by integrating third-party services for payments, fulfillment, and more.

## Create an Ecommerce Store on Cloud

Create a Cloud project from the DTC starter to get an ecommerce store powered by Medusa. Follow the [Create Your First Project](!cloud!/first-project#option-1-choose-a-starter) guide to create the project.

The project includes:

- The Medusa application, which is composed of a Node.js server and a Medusa Admin dashboard. Cloud deploys it with a database, Redis, and file storage, so you can open the deployed Medusa Admin and start managing your store's data.
- A [Next.js Starter Storefront](../../nextjs-starter/page.mdx) that connects to your Medusa application to provide customers with ecommerce features.

Cloud clones the starter into a GitHub repository in your account or organization. To customize the store, set up the project on your machine by following the [Set Up Medusa Locally](!cloud!/setup-locally) guide.

## Publish Changes to Cloud

Your Cloud project is connected to its GitHub repository, so you deploy changes by pushing them:

- Push to a branch connected to an environment to deploy to it.
- Open a pull request to test changes in a preview environment.
- Merge the pull request to deploy the changes to production.

Cloud hosts your server, Medusa Admin, storefront, database, and Redis instance, so you don't need to configure, scale, or maintain infrastructure.
