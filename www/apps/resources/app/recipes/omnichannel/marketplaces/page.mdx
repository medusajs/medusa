## Choose an Integration Approach

Marketplace integrations generally use one of the following approaches:

- **Product feed**: You expose an [API route](!docs!/learn/fundamentals/api-routes) that returns your product catalog in the format the channel expects, such as XML or CSV. The channel pulls the feed periodically. This approach is one-way and fits channels that only list your products and redirect customers to your storefront for checkout. The [Meta and Google product feed](../../../how-to-tutorials/tutorials/product-feed/page.mdx) tutorial shows this approach.
- **API sync**: You call the marketplace's API to create and update listings, and you import orders placed on the marketplace into Medusa. This approach is two-way and fits marketplaces that handle checkout themselves, such as Amazon, eBay, Walmart, and TikTok Shop.

## General Approach to Integrate a Marketplace

The following steps describe how to integrate a marketplace using the API sync approach. They build on the generic [Integrate Third-Party Systems](!docs!/learn/customization/integrate-systems) pattern.

### 1. Create a Sales Channel for the Marketplace

Create a [sales channel](../../../commerce-modules/sales-channel/page.mdx) for each marketplace, such as "Amazon" or "TikTok Shop". Then, add to the sales channel the products you want to sell on that marketplace.

The sales channel lets you:

- Control which products you sync to the marketplace.
- Track orders that customers placed on the marketplace.
- Associate the marketplace with specific stock locations to manage its inventory.

### 2. Integrate the Marketplace in a Module

Create a [module](!docs!/learn/fundamentals/modules) whose service wraps the marketplace's API client. For example, the service has methods to create listings, update stock quantities, retrieve new orders, and mark orders as shipped.

Pass the marketplace's credentials, such as API keys or OAuth client details, as [module options](!docs!/learn/fundamentals/modules/options), and store their values in environment variables.

If you need to store marketplace data in Medusa, such as the ID of a listing on the marketplace, create a data model in the module and [link it](!docs!/learn/fundamentals/module-links) to the related Medusa data model, such as a product variant.

### 3. Sync Products and Prices

Create a [workflow](!docs!/learn/fundamentals/workflows) that retrieves products in the marketplace's sales channel and creates or updates their listings using your module's service. Then, execute the workflow from:

- A [subscriber](!docs!/learn/fundamentals/events-and-subscribers) that listens to [product events](/references/product/events), such as `product.updated`, to sync changes as they happen.
- A [scheduled job](!docs!/learn/fundamentals/scheduled-jobs) that runs a full sync periodically to catch any missed changes.

### 4. Sync Inventory

Keep the marketplace's stock quantities in sync with Medusa to avoid overselling. Create a workflow that retrieves the inventory levels of the synced variants and updates the marketplace. Execute it from a scheduled job, or from a subscriber that listens to [Inventory Module events](/references/inventory/events).

### 5. Import Marketplace Orders

Import orders placed on the marketplace into Medusa so that you fulfill all orders from one system:

- If the marketplace sends webhooks, create an [API route](!docs!/learn/fundamentals/api-routes) that receives them. Use the [raw request body](!docs!/learn/fundamentals/api-routes/parse-body#preserve-raw-body-data-for-webhooks) to verify the webhook's signature.
- Otherwise, create a scheduled job that retrieves new orders from the marketplace periodically.

In both cases, create the order in a workflow that uses Medusa's [createOrderWorkflow](/references/medusa-workflows/createOrderWorkflow), and set the order's sales channel to the marketplace's sales channel. Store the marketplace's order ID, for example in the order's `metadata`, to avoid importing the same order twice.

### 6. Sync Fulfillment and Order Changes Back

When you fulfill, ship, or cancel a marketplace order in Medusa, update the order on the marketplace. Create subscribers that listen to [order events](/references/order/events), such as `order.fulfillment_created` and `order.canceled`, and execute a workflow that updates the order on the marketplace using your module's service.

<Note title="Tip">

Marketplace APIs often have strict rate limits. Refer to the [Best Practices for Third-Party Syncing](!docs!/learn/best-practices/third-party-sync) chapter to learn how to batch requests, retry errors, and avoid memory issues when syncing large catalogs.

</Note>
