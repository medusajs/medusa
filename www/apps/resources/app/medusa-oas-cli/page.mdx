# {metadata.title}

The `medusa-oas-cli` is a command-line tool for generating and processing OpenAPI specifications from Medusa applications. It helps you create API documentation by scanning your Medusa backend and generating comprehensive OpenAPI (OAS) YAML files.

## Installation

The CLI is available as part of the `@medusajs/oas` package:

```bash
npm install @medusajs/oas
```

## Usage

```bash
medusa-oas-cli [options]
```

## Examples

### Basic Usage

Generate OpenAPI documentation from a source file:

```bash
medusa-oas-cli --src-file ./openapi.yaml --out-dir ./docs/api
```

### With Custom Configuration

Use a custom configuration file:

```bash
medusa-oas-cli --src-file ./openapi.yaml --out-dir ./docs/api --config ./oas.config.js
```

### Dry Run

Test your configuration without generating files:

```bash
medusa-oas-cli --src-file ./openapi.yaml --out-dir ./docs/api --dry-run
```

### Archive to Versioned Storage

Generate documentation and archive the bundled YAML file:

```bash
medusa-oas-cli \
  --src-file ./openapi.yaml \
  --out-dir ./docs/api \
  --archive-out-file ./archive/v1.0.0/openapi.yaml
```

## Features

- **OpenAPI Processing**: Processes and sanitizes OpenAPI specifications
- **Circular Reference Fixing**: Automatically resolves circular references in your API schema
- **Custom Configuration**: Support for custom configuration files
- **Dry Run Mode**: Test your setup without generating files
- **Versioned Archiving**: Archive generated specifications for versioning with `--archive-out-file`
