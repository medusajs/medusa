# {metadata.title}

In this guide, you'll learn how to manage user roles in your store using Role-Based Access Control (RBAC).

<Note>

This feature is available under the `rbac` feature flag. Learn how to enable it in the [Feature Flags guide](!docs!/learn/debugging-and-testing/feature-flags).

</Note>

## View Roles

You can view all admin user roles by going to Settings → Users → Roles. In the list, you can see role details such as the name, description, and number of users assigned to each role. You can also search, filter, and sort roles to find specific items.

---

## View Role Details

To view the details of a role:

1. Go to Settings → Users → Roles.
2. Click on the role in the list.

This opens the role's details page where you can also manage the role.

---

## Create a New Role

To create a new admin role:

1. Go to Settings → Users → Roles.
2. Click the Create button.
3. In the form that opens:
    - Enter the role's name.
    - Optionally, enter a description.
    - Optionally, assign policies to the role by selecting them from the list.
4. Click the Create button.

The role is created and you're taken to its details page.

---

## Edit Role Details

To edit a role's basic details:

1. Go to the role's details page.
2. In the General section, click the three-dots icon and choose Edit.
3. In the form that opens, edit the role's name and description.
4. Click Save.

---

## Manage Role Policies

Policies define what actions a role can perform. To manage a role's policies:

1. Go to the role's details page.
2. In the Policies section, you can:
    - **Add policies**: Click the Add button, select policies from the list, and click Save.
    - **Remove policies**: Click the X button next to any policy to remove it.

<Note>

You can only assign policies that you have permission to assign. The list shows only policies you're authorized to manage.

</Note>

---

## Manage Role Users

To manage which users are assigned to a role:

1. Go to the role's details page.
2. In the Users section, you can:
    - **Add users**: Click the Add button, select users from the list, and click Save.
    - **Remove users**: Click the X button next to any user to remove them from the role.

---

## Delete a Role

<Note type="warning">

Deleting a role is irreversible. All users assigned to this role will lose those permissions.

</Note>

To delete a role:

1. Go to Settings → Users → Roles.
2. Find the role in the list and click on it.
3. In the General section, click the three-dots icon and choose Delete.
4. Confirm deletion by entering the role's name and clicking Delete.
