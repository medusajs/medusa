# {metadata.title}

In this guide, you'll learn how to manage invites in your store.

## Add Admin Users through Invites

To add a new user to your team, you must invite them. The user gets a notification of the invite to sign up, but you can also manually send them the invite link to sign up.

<Note title="Cloud user?">

Make sure you've set up [Medusa Emails](!cloud!/emails) in your Cloud project to send admin user invite emails. Medusa Emails is a managed email service that allows you to send transactional emails with zero configuration.

</Note>

---

## Invite a User

<PermissionsBadge permissions={["invite:create", "invite:read"]} />

To send an invite to a user:

1. Go to Settings → Users.
2. Click the Invite button.
3. Enter the user’s email.
4. If your store uses the role-based access control (RBAC) feature, you can select the roles to assign the user in the optional **Roles** field. The user gets these roles when they accept the invite.
5. Once done, click on the "Send invite" button.

![Invite user form](https://res.cloudinary.com/dza7lstvk/image/upload/v1739964961/User%20Guide/Screenshot_2025-02-19_at_1.35.52_PM_rewdrm.png)

### Assign Roles in Invites

The **Roles** field only appears if your store uses the RBAC feature and you have the `rbac_role:read` policy. The field only lists the roles that you can assign, which are the roles whose policies you hold yourself.

If you don't select any roles, the user has no permissions after accepting the invite. They see a **No permissions yet** page until you [assign them a role](../../roles/page.mdx#assign-users-to-a-role).

## View Pending Invites

<PermissionsBadge permissions={["invite:create", "invite:read"]} />

To view pending invites:

1. Go to Settings → Users.
2. Click the Invite button.
3. Below the form, you'll find a Pending Invites table with all the invites that haven't been accepted yet. If your store uses the RBAC feature, the table also shows the roles of each invite.

![Pending invites table](https://res.cloudinary.com/dza7lstvk/image/upload/v1739964999/User%20Guide/Screenshot_2025-02-19_at_1.36.30_PM_jvkqcw.png)

## Resend an Invite

<PermissionsBadge permissions={["invite:create", "invite:read", "invite:update"]} />

You can resend an invite if the user hasn't received it, they lost their link, or the invite has expired.

To resend an invite to a user:

1. Go to Settings → Users.
2. Click the Invite button.
3. In the Pending Invites table, find the user to resend their invite and click on the <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> icon.
4. Choose "Resend invite" from the dropdown.

A notification will be sent to the user [as configured by your technical team](!resources!/infrastructure-modules/notification).

---

## Get Invite Link

<PermissionsBadge permissions={["invite:create", "invite:read"]} />

In addition to sending the user an invite, you can copy the invite link and send it manually to the user.

To copy the invite link:

1. Go to Settings → Users.
2. Click the Invite button.
3. In the Pending Invites table, find the user to resend their invite and click on the <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> icon.
3. Choose “Copy invite link” from the dropdown.

You can then send this link to the user to sign up.

---

## Delete Invite

<PermissionsBadge permissions={["invite:create", "invite:read", "invite:delete"]} />

<Note type="warning">

Deleting an invite will revoke the invite and the user won't be able to sign up using that invite link.

</Note>

To delete an invite:

1. Go to Settings → Users.
2. Click the Invite button.
3. In the Pending Invites table, find the user to resend their invite and click on the <InlineIcon Icon={EllipsisHorizontal} alt="three-dots" /> icon.
4. Choose Delete from the dropdown.
5. Confirm deleting the invite by clicking the Delete button in the pop-up.
